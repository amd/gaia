## What GAIA can do

GAIA can read projects, files, issues and merge requests on GitLab.com, and create or update them if the token allows. Use a `read_api` token to keep it read-only.

## Connect it

1. In the Agent UI, click **Connectors** in the sidebar and open the **GitLab** tile.

2. **GitLab Personal Access Token:** Create a token under [User settings → Access tokens](https://gitlab.com/-/user_settings/personal_access_tokens) with the `api` scope, or `read_api` to keep GAIA read-only.

3. Click **Save**. GAIA starts the connector once to check it.

Each value is stored in your OS credential store, never in a plain file.

From a terminal instead:

```bash
gaia connectors configure mcp-gitlab --set GITLAB_PERSONAL_ACCESS_TOKEN=...
```

## Use it

Ask in chat, for example: "Which of my merge requests are waiting for review?"

GAIA loads no connector tools once the connectors switched on for it add up to more than 50 tools. If it says some were not loaded, switch off the ones you are not using.

## Disconnect

Open the tile and click **Disconnect** (or `gaia connectors disconnect mcp-gitlab`). Revoke the token at the service too if it may have leaked.
