## What GAIA can do

GAIA can list bases and tables and read records, and edit records if the token has write access. It only sees the bases you picked for the token.

## Connect it

1. In the Agent UI, click **Connectors** in the sidebar and open the **Airtable** tile.

2. **Airtable personal access token:** Create a token at [airtable.com/create/tokens](https://airtable.com/create/tokens) with `schema.bases:read` and `data.records:read` (add `data.records:write` to let GAIA edit), and pick the bases it may use.

3. Click **Save**. GAIA starts the connector once to check it.

Each value is stored in your OS credential store, never in a plain file.

From a terminal instead:

```bash
gaia connectors configure mcp-airtable --set AIRTABLE_API_KEY=...
```

## Use it

Ask in chat, for example: "Show the open rows in my Content calendar base."

GAIA loads no connector tools once the connectors switched on for it add up to more than 50 tools. If it says some were not loaded, switch off the ones you are not using.

## Disconnect

Open the tile and click **Disconnect** (or `gaia connectors disconnect mcp-airtable`). Revoke the token at the service too if it may have leaked.
