</Info>

## What GAIA can do

GAIA can look up current documentation and code examples for a library by name. Nothing to sign in to.

## Connect it

In the Agent UI, click **Connectors** in the sidebar, open the **Context7** tile, and click **Connect**. There is no key to enter.

From a terminal instead:

```bash
gaia connectors configure mcp-context7
```

## Use it

Ask in chat, for example: "How do I stream a response with the latest FastAPI?"

GAIA loads no connector tools once the connectors switched on for it add up to more than 50 tools. If it says some were not loaded, switch off the ones you are not using.

## Disconnect

Open the tile and click **Disconnect** (or `gaia connectors disconnect mcp-context7`).
