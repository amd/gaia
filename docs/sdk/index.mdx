The Python `Agent` base class owns the inference/tool loop. Concrete agents add
instructions and tools; clients such as the TUI handle presentation and transport.
A packaged agent is a separate dependency, not a class guaranteed to ship in the
core wheel.

| Surface | Reference |
| --- | --- |

| Tool schemas, registration, permissions, and timeouts | [Tools](/sdk/core/tools) |
| Console and event output | [Console](/sdk/core/console) |
| Terminal transports, state, and debugging | [TUI architecture](/reference/tui) |
| Reusable capability mixins | [Tool mixins](/sdk/mixins/tool-mixins) |
| Programmatic conversation | [Agent SDK](/sdk/sdks/chat) |

For a runnable example, use the [quickstart](/quickstart). For the flagship's
capabilities and supported entry points, see [GAIA agent](/guides/gaia).
Local inference uses Lemonade; [cloud provider selection](/guides/ai-providers)
is explicit and changes where conversation data is sent.
