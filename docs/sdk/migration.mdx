# Migration Guide

<Badge text="development" color="orange" />

## From a Local Agent Class to an External Package

`src/gaia/agents/` holds only the framework; shipped agents are packages under
`hub/agents/<id>/python/`. Your own agent belongs in its own package.

**Before** (an agent class inside your application):
```python
# my_app/agent.py
from gaia.agents.base.agent import Agent

class MyAgent(Agent):
    # Implementation
    pass
```

**After** (external package):
```python
# my-gaia-agent/src/my_agent/agent.py
from gaia.agents.base.agent import Agent

class MyAgent(Agent):
    # Same implementation
    pass

# pyproject.toml
[project.entry-points."gaia.agents"]
my-agent = "my_agent.agent:MyAgent"
```

Installation:
```bash
pip install my-gaia-agent
# Agent auto-discovered by GAIA!
```
