# Configuration

<Badge text="development" color="orange" />

## 16.1 Environment Variables

```bash
# LLM Configuration
export LEMONADE_BASE_URL="http://localhost:13305/api/v1"
# Required only when connecting to an authenticated remote Lemonade.
# See https://lemonade-server.ai/docs/guide/configuration/#api-key-and-security
export LEMONADE_API_KEY=""

# API server (gaia api). These are read as the literal string "1" —
# any other value (including "true") leaves the feature OFF.
export GAIA_API_DEBUG="1"      # debug logging + console output
export GAIA_API_STREAMING="1"  # stream LLM responses over the API

# Runs approval-gated tools (shell commands, file writes) with NO user
# confirmation, on every surface — not just the API. Trusted single-user
# localhost only; see /sdk/infrastructure/api-server. Read from the startup
# environment, so a project .env cannot switch it on.
export GAIA_AUTO_APPROVE_TOOLS="1"

# Skip loading .env files ("1", "true", "yes" or "on"). For an app that embeds
# GAIA and supplies its own environment. Read from the startup environment, so
# a .env file cannot turn it on or off.
export GAIA_NO_DOTENV="1"

# Variables to withhold from the processes GAIA starts for an agent (shell
# commands, MCP servers, CLI installers, native hub agents, media tools, the
# Lemonade server), comma or space separated. GAIA's own internal
# credentials are always withheld; this adds yours to the list.
export GAIA_CHILD_ENV_DENY="MY_APP_TOKEN,MY_DB_PASSWORD"

# API Keys (for cloud providers)
export ANTHROPIC_API_KEY="sk-ant-..."
```

<Note>
GAIA has no `GAIA_LOG_LEVEL` environment variable. Log levels are set
programmatically through `gaia.logger` (`set_level(name, level)`); the default
is `INFO`.
</Note>

`~/.gaia/gaia.log` is size-capped and shared safely by every GAIA process. Two
variables tune the cap:

| Variable | Default | Effect |
|----------|---------|--------|
| `GAIA_LOG_MAX_MB` | `10` | Size at which `gaia.log` rotates to `gaia.log.1` |
| `GAIA_LOG_BACKUPS` | `3` | Rotated copies kept (`gaia.log.1` … `gaia.log.N`) |

Both must be whole numbers of at least 1; any other value stops GAIA at startup
with an error naming the variable.

## Local context window

Overrides below 32,768 tokens emit a warning because agent prompts may be truncated.
The requested value is still honored; increase or unset it if replies are empty.

Set `GAIA_CTX_SIZE` to a positive integer token count to override the requested
context window for CLI startup, agent construction, installer verification and
subsequent local-model reloads. For example:

```bash
GAIA_CTX_SIZE=131072 gaia chat
```

Without an override, each model gets its own window. GPU/CPU models default to
65,536 tokens, and unknown local models use the same default. Registered models
keep their own default, and a registered model that declares its native maximum
and its KV-cache cost per token is sized to this machine's memory: the largest
8,192-token step whose KV cache fits beside the weights, the embedder (on shared
memory) and 10% headroom, up to that maximum and never below its default. NPU
(FLM) models are capped at 32,768 tokens with a warning; `default_device = npu`
does not cap a GPU model. Invalid nonempty values fail with an actionable error;
unset or blank values use the default.

## Per-request time budget

A long document arrives as one large prefill, and the bigger the context window
the longer that takes. GAIA derives the budget from the window rather than
keeping a separate number that can drift from it: 32,768 tokens gets 1,024
seconds, 65,536 gets 2,048, and everything is capped at 3,600 so a wedged
request still ends. `GAIA_CTX_SIZE` moves it too.

The same value is used at both ends — the private Lemonade instance's
`global_timeout` and GAIA's own client read timeout — so the server cannot be
allowed more time than the client will wait.

Set `GAIA_LEMONADE_REQUEST_BUDGET` to a positive integer number of seconds to
override it on a machine slower than that assumption:

```bash
GAIA_LEMONADE_REQUEST_BUDGET=3000 gaia chat
```

Invalid nonempty values fail with an actionable error rather than falling back
to the derived number; unset or blank values use it. This applies to the
embedded Lemonade instance GAIA owns — a system-wide install keeps its own
settings.

Larger windows require model support and more KV-cache memory. The override is a
requested window, not proof of the backend's effective capacity. A model already
loaded with a sufficient window is reused; lowering the value takes effect on the
next load rather than forcing eviction. SDK `ctx_size_override` remains a separate
instance-scoped exact pin and takes precedence over this environment variable.

Installer verification uses the profile being installed, even before it is saved.
This setting does not change overflow recovery; it controls requested load capacity.

## 16.2 Configuration in Code

```python
import os

# Read configuration
base_url = os.getenv("LEMONADE_BASE_URL", "http://localhost:13305/api/v1")
debug = os.getenv("GAIA_API_DEBUG") == "1"  # matches how gaia api reads it

# Use in agent
agent = MyAgent(
    base_url=base_url,
    debug_prompts=debug
)
```
