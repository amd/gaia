# Configuration

<Badge text="development" color="orange" />

## 16.1 Environment Variables

```bash
# LLM Configuration
export LEMONADE_BASE_URL="http://localhost:13305/api/v1"
# Required only when connecting to an authenticated remote Lemonade.
# See https://lemonade-server.ai/docs/guide/configuration/#api-key-and-security
export LEMONADE_API_KEY=""

# API server (gaia api). These are read as the literal string "1" —
# any other value (including "true") leaves the feature OFF.
export GAIA_API_DEBUG="1"      # debug logging + console output
export GAIA_API_STREAMING="1"  # stream LLM responses over the API

# Runs approval-gated tools (shell commands, file writes) with NO user
# confirmation, on every surface — not just the API. Trusted single-user
# localhost only; see /sdk/infrastructure/api-server. Read from the startup
# environment, so a project .env cannot switch it on.
export GAIA_AUTO_APPROVE_TOOLS="1"

# API Keys (for cloud providers)
export ANTHROPIC_API_KEY="sk-ant-..."
export OPENAI_API_KEY="sk-..."
```

<Note>
GAIA has no `GAIA_LOG_LEVEL` environment variable. Log levels are set
programmatically through `gaia.logger` (`set_level(name, level)`); the default
is `INFO`.
</Note>

## Local context window

Set `GAIA_CTX_SIZE` to a positive integer token count to override the requested
context window for CLI startup and subsequent local-model reloads. For example:

```bash
GAIA_CTX_SIZE=131072 gaia chat
```

The GPU/CPU profile defaults to 65,536 tokens; unknown local models use the same
profile default. Registered models retain their own default when no override is
set. NPU/FLM requests are capped at 32,768 tokens with a warning. Invalid nonempty
values fail with an actionable error; unset or blank values use the default.

Larger windows require model support and more KV-cache memory. The override is a
requested window, not proof of the backend's effective capacity. A model already
loaded with a sufficient window is reused; lowering the value takes effect on the
next load rather than forcing eviction. SDK `ctx_size_override` remains a separate
instance-scoped exact pin and takes precedence over this environment variable.

This setting does not change installer profile defaults or overflow recovery.

## 16.2 Configuration in Code

```python
import os

# Read configuration
base_url = os.getenv("LEMONADE_BASE_URL", "http://localhost:13305/api/v1")
debug = os.getenv("GAIA_API_DEBUG") == "1"  # matches how gaia api reads it

# Use in agent
agent = MyAgent(
    base_url=base_url,
    debug_prompts=debug
)
```
