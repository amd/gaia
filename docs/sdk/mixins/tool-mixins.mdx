**Purpose:** Reusable tool sets that can be mixed into your agents.

**Available Mixins:** The registry exposes 21 mixins (table below). Detailed specs exist for some of them; see [Specifications → Tool Mixins](/spec/file-tools-mixin)

## Composable mixins (registry)

The agent registry exposes these mixins by name in `KNOWN_TOOLS`
([`src/gaia/agents/registry.py`](https://github.com/amd/gaia/blob/main/src/gaia/agents/registry.py)).
A [custom agent](/guides/custom-agent) composes any of them by inheriting the
mixin and calling its `register_*_tools()` method. Each row is the exact
`name → module.Class` mapping the registry resolves:

| Tool name | Import | Purpose |
|-----------|--------|---------|
| `rag` | `from gaia.agents.tools.rag_tools import RAGToolsMixin` | Document retrieval |
| `code_index` | `from gaia.agents.tools.code_index_tools import CodeIndexToolsMixin` | Semantic code search (FAISS) |
| `file_search` | `from gaia.agents.tools.file_tools import FileSearchToolsMixin` | Fuzzy/glob file search |
| `file_io` | `from gaia.agents.tools.file_io_tools import FileIOToolsMixin` | Read/write/edit files |
| `file_monitor` | `from gaia.agents.tools.file_monitor_tools import FileToolsMixin` | Watch directories for new documents |
| `shell` | `from gaia.agents.tools.shell_tools import ShellToolsMixin` | Sandboxed shell commands |
| `cli_setup` | `from gaia.agents.tools.cli_setup_tools import CliSetupToolsMixin` | Install and sign in to a skill's CLI ([how it works](/guides/gaia#setting-up-a-cli-a-skill-needs)) |
| `screenshot` | `from gaia.agents.tools.screenshot_tools import ScreenshotToolsMixin` | Screen capture |
| `filesystem` | `from gaia.agents.tools.filesystem_tools import FileSystemToolsMixin` | File system navigation |
| `scratchpad` | `from gaia.agents.tools.scratchpad_tools import ScratchpadToolsMixin` | SQL scratchpad tables for data analysis |
| `browser` | `from gaia.agents.tools.browser_tools import BrowserToolsMixin` | Web search, page fetch, download |
| `browser_use` | `from gaia.agents.tools.browser_use_tools import BrowserUseToolsMixin` | Live-browser tools: open, observe, act, and sign in |
| `email` | `from gaia.agents.tools.email_tools import EmailToolsMixin` | Read-only mailbox tools (Gmail / Outlook) |
| `sd` | `from gaia.sd.mixin import SDToolsMixin` | Stable Diffusion image generation |
| `vlm` | `from gaia.vlm.mixin import VLMToolsMixin` | Vision LLM / structured extraction |
| `skills` | `from gaia.agents.tools.skill_library_tools import SkillLibraryToolsMixin` | Model-driven skill library (list/search/install/load/unload) |
| `skill_learning` | `from gaia.agents.tools.skill_learning_tools import SkillLearningToolsMixin` | Persist lessons learned while running a skill |
| `audio` | `from gaia.agents.tools.audio_tools import AudioToolsMixin` | Transcribe audio, video or a video link via Lemonade, label speakers, extract a timestamped list, export subtitles |
| `audio_generation` | `from gaia.agents.tools.audio_generation_tools import AudioGenerationToolsMixin` | Generate WAV music and sound effects via Lemonade (`init_audio_generation`) |
| `wait` | `from gaia.agents.tools.wait_tools import WaitToolsMixin` | `sleep` up to 300 s, e.g. until a rate limit resets; ends early on Stop |
| `reasoning_effort` | `from gaia.agents.tools.reasoning_tools import ReasoningEffortToolsMixin` | `set_reasoning_effort` low/medium/high per step, on models that grade reasoning (gpt-oss) |

The sections below show usage patterns for the most common mixins; the
`file_io` mixin has its own spec at [FileIOToolsMixin](/spec/file-io-tools-mixin).

## 9.1 File Watching Mixin

**Detailed Spec:** [FileToolsMixin](/spec/file-tools-mixin)

The chat-tools `FileToolsMixin` is narrowly scoped to **watching** directories
for new documents; it does not register read/write/list tools. Use
`FileSearchToolsMixin` (§9.4 below) when you need generic filesystem I/O.

```python
from gaia.agents.base.agent import Agent
from gaia.agents.tools.file_monitor_tools import FileToolsMixin

class MyAgent(Agent, FileToolsMixin):
    """Agent that can watch directories for new files."""

    def _register_tools(self):
        self.register_file_tools()
        # Registers: add_watch_directory(directory: str) -> dict
```

## 9.2 RAG Tools Mixin

**Import:** `from gaia.agents.tools.rag_tools import RAGToolsMixin`
**Detailed Spec:** [RAGToolsMixin](/spec/rag-tools-mixin)

```python
from gaia.agents.base.agent import Agent
from gaia.agents.tools.rag_tools import RAGToolsMixin
from gaia.rag import RAGConfig, RAGSDK

class MyAgent(Agent, RAGToolsMixin):
    """Agent with document Q&A tools."""

    def __init__(self, documents_path: str = "./docs", **kwargs):
        self.documents_path = documents_path
        self.rag = RAGSDK(RAGConfig())  # bind before super().__init__()
        super().__init__(**kwargs)

    def _register_tools(self):
        self.register_rag_tools()
        # Registers:
        # - query_documents(query, debug=False)
        # - query_specific_file(file_path, query)
        # - search_indexed_chunks(pattern)
        # - index_document(file_path)            # singular — one file per call
        # - index_directory(directory_path, recursive=False)
        # - list_indexed_documents()
        # - summarize_document(file_path, summary_type="detailed",
        #                      max_words_per_section=20000)
        # - dump_document(file_name, output_path=None)
        # - evaluate_retrieval(question, retrieved_info)
        # - rag_status()
```

from gaia.agents.base.agent import Agent

class MyAgent(Agent, ShellToolsMixin):
    """Agent that can execute shell commands."""

## 9.4 File Search Mixin

**Import:** `from gaia.agents.tools.file_tools import FileSearchToolsMixin`
**Detailed Spec:** [FileSearchToolsMixin](/spec/file-search-mixin)

`FileSearchToolsMixin` is the general-purpose filesystem toolbox — it's what
powers `read_file` / `write_file` in the chat agent.

```python
from gaia.agents.base.agent import Agent
from gaia.agents.tools.file_tools import FileSearchToolsMixin

class MyAgent(Agent, FileSearchToolsMixin):
    """Agent with generic file I/O and search capabilities."""

    def _register_tools(self):
        self.register_file_search_tools()
        # Registers:
        # - search_file(file_pattern, directory=None, deep_search=False, file_types=None)
        # - search_directory(directory_name, search_root=None, max_depth=4)
        # - search_file_content(pattern, directory=".", file_pattern=None,
        #                       case_sensitive=False, context_lines=0)
        # - read_file(file_path, offset=0, limit=None)
        # - write_file(file_path, content, create_dirs=True)
        # - edit_file(file_path, old_content, new_content)
        # - browse_directory(directory_path=None, show_hidden=False, sort_by="name")
        # - get_file_info(file_path)
        # - analyze_data_file(file_path, ...)
        # - list_recent_files(location="all", ...)
```

## 9.5 Stable Diffusion Mixin

**Import:** `from gaia.sd import SDToolsMixin`
**Source:** [`src/gaia/sd/mixin.py`](https://github.com/amd/gaia/tree/main/src/gaia/sd/mixin.py)

```python
from gaia.agents.base.agent import Agent
from gaia.sd import SDToolsMixin

class MyImageAgent(Agent, SDToolsMixin):
    """Agent with image generation tools."""

    def __init__(self):
        super().__init__(
            model_id="Qwen3-8B-GGUF",  # LLM for orchestration
            min_context_size=8192,  # 8K sufficient for SD
        )

        # Initialize SD tools (auto-registers generate_image, list_sd_models, etc.)
        # Images save to ~/.gaia/cache/sd/images unless you pass output_dir=.
        self.init_sd(
            default_model="SDXL-Turbo",  # Fast, good quality
        )

    def _register_tools(self):
        pass  # Tools already registered by init_sd()

    def _get_system_prompt(self):
        return "You generate images. Use generate_image with enhanced prompts."

# Usage
agent = MyImageAgent()
result = agent.process_query("create a sunset over mountains")
# Agent enhances prompt and calls generate_image automatically
```

**Available Tools:**
- `generate_image(prompt, model, size, steps, cfg_scale, seed)` - Generate images with SD
- `list_sd_models()` - List the image models downloaded in Lemonade, with each one's `image_defaults`
- `get_generation_history(limit)` - See generated images from session

To opt into image-to-3D reconstruction, initialize the mixin with
`enable_3d_tools=True`. This adds
`generate_3d_model(image_path, model="TRELLIS-3D", resolution=512, seed=42, bg_removal="threshold")`,
which sends a local image to Lemonade's `/v1/3d/generations` endpoint and saves
the returned GLB mesh. The selected TRELLIS model must already be downloaded;
GAIA does not silently download it.

To opt into image variations, initialize the mixin with
`enable_variation_tools=True`. This adds
`create_image_variation(image_path, model=None, size=None, n=1)` (`None` resolves to Flux-2-Klein-4B),
which sends a local PNG to Lemonade's `/v1/images/variations` endpoint (no
prompt) and saves each of the `n` (1-10) results as its own PNG next to
generated images. The source image must be inside the agent's allowed folders,
must be a real PNG (checked by its signature, not its extension) of at most
20 MiB, and `size` sides are capped at 4096. These checks run before any model
is loaded or downloaded.
As with `generate_image`, the model must already be downloaded; only the legacy
SD models download on demand.
The same call is available directly as `LemonadeClient.create_image_variation()`.

**Supported Models:**
- **SDXL-Turbo** (default) - Fast, 512x512, ~17s
- **SD-Turbo** - Faster, 512x512, ~13s
- **SDXL-Base-1.0** - Photorealistic, 1024x1024, ~9min
- **SD-1.5** - Legacy, 512x512, ~88s
- **TheNoise models** (e.g. `Qwen-Image-2.1-Turbo-INT8`) - must already be downloaded; GAIA leaves size, steps, CFG and seed to Lemonade's per-model defaults unless you pass them

## 9.6 Vision Language Model Mixin

**Import:** `from gaia.vlm import VLMToolsMixin`
**Source:** [`src/gaia/vlm/mixin.py`](https://github.com/amd/gaia/tree/main/src/gaia/vlm/mixin.py)

```python
from gaia.agents.base.agent import Agent
from gaia.vlm import VLMToolsMixin

class MyVisionAgent(Agent, VLMToolsMixin):
    """Agent with vision analysis tools."""

    def __init__(self):
        super().__init__(min_context_size=8192)

        # Initialize VLM tools (auto-registers analyze_image and answer_question_about_image)
        self.init_vlm(model="Qwen3-VL-4B-Instruct-GGUF")

    def _register_tools(self):
        pass  # Tools already registered by init_vlm()

    def _get_system_prompt(self):
        return "You analyze images. Use VLM tools for descriptions and Q&A."

# Usage
agent = MyVisionAgent()
result = agent.process_query("analyze this image: photo.jpg")
# Agent calls analyze_image automatically
```

**Available Tools:**
- `analyze_image(image_path, focus)` - Get detailed image description
- `answer_question_about_image(image_path, question)` - Answer specific questions

**Focus Options:** `composition`, `colors`, `mood`, `details`, `all` (default)

Need something the mixin doesn't cover — image captioning, storytelling, structured
extraction? Register your own `@tool` that calls `self.vlm_client` directly; see
[`examples/sd_agent_example.py`](https://github.com/amd/gaia/tree/main/examples/sd_agent_example.py).

## 9.7 Other registry mixins

Tool lists for more of the `KNOWN_TOOLS` mixins, read from `src/gaia/agents/tools/`. Call the mixin's register method from `_register_tools()`; tools run through `agent._execute_tool(name, args)`. The `email`, `code_index` and `browser` mixins are not covered here; `file_io` has its own spec (linked above).

### `cli_setup` — `CliSetupToolsMixin`

Register with `register_cli_setup_tools()`.

| Tool | Purpose |
|------|---------|
| `check_cli_setup(binary: str)` | Check whether a skill's CLI is installed and signed in |
| `install_cli(binary: str, command: str)` | Install a skill's CLI with this machine's package manager |
| `sign_in_cli(binary: str, command: str)` | Sign a CLI in to the user's account through their browser |

### `screenshot` — `ScreenshotToolsMixin`

Register with `register_screenshot_tools()`.

| Tool | Purpose |
|------|---------|
| `take_screenshot(output_path: str = "")` | Capture the screen and save it to a file |

### `filesystem` — `FileSystemToolsMixin`

Register with `register_filesystem_tools()`.

| Tool | Purpose |
|------|---------|
| `browse_directory(path=".", show_hidden=False, sort_by="name", filter_type=None, max_items=50)` | List a directory with metadata |
| `tree(path=".", max_depth=3, show_sizes=False, include_pattern=None, exclude_pattern=None, dirs_only=False)` | Show a directory tree |
| `file_info(path: str)` | Detailed information about a file or directory |
| `find_files(query, search_type="auto", scope="smart", file_types=None, size_range=None, date_range=None, max_results=25, sort_by="relevance")` | Search for files by name, content or metadata |
| `read_file(file_path, lines=100, encoding="auto", mode="full", offset=0, limit=None)` | Read a file with type-based analysis |
| `bookmark(action="list", path=None, label=None)` | Save, list or remove bookmarks |

### `scratchpad` — `ScratchpadToolsMixin`

Register with `register_scratchpad_tools()`.

| Tool | Purpose |
|------|---------|
| `create_table(table_name: str, columns: str)` | Create a table for extracted data |
| `insert_data(table_name: str, data: str)` | Insert rows into a table |
| `query_data(sql: str)` | Run a SQL `SELECT` against the scratchpad database |
| `list_tables()` | List tables with schemas and row counts |
| `drop_table(table_name: str)` | Remove a table when analysis is done |

### `browser_use` — `BrowserUseToolsMixin`

Register with `register_browser_use_tools()`. Drives a real browser; see the [browser-use plan](/plans/browser-use).

| Tool | Purpose |
|------|---------|
| `browser_open(url: str)` | Open a URL and list its interactive elements |
| `browser_snapshot()` | Re-read the current page's interactive elements |
| `browser_click(ref: str)` | Click an element |
| `browser_type(ref: str, text: str, press_enter: bool = False)` | Type into a field or choose a dropdown option |
| `browser_login(url: str)` | Ask the user to sign in, then save the session |
| `browser_back()` | Go back, or close a tab and return to its opener |
| `browser_find(text: str)` | Search the page for text and return the surroundings |
| `browser_sessions()` | List sites with a saved sign-in |

### `skills` — `SkillLibraryToolsMixin`

Register with `register_skill_library_tools()`.

| Tool | Purpose |
|------|---------|
| `list_skills()` | List installed skills, loaded or not |
| `search_skill_hub(query: str = "")` | Search the skill hub for skills to install |
| `install_skill(name: str, version: str = "*")` | Download a skill into `~/.gaia/skills` |
| `capture_skill(source: str, name: str = "")` | Capture a skill from pasted `SKILL.md` text, a URL or a local path |
| `remove_skill(name: str)` | Delete an installed skill |
| `load_skill(name: str)` | Activate a skill and show its instructions |
| `unload_skill(name: str)` | Deregister a loaded skill's tools and instructions |
| `skill_status()` | Report which skills are loaded and what they cost |

### `skill_learning` — `SkillLearningToolsMixin`

Register with `register_skill_learning_tools()`.

| Tool | Purpose |
|------|---------|
| `remember_skill_lesson(skill, section, corrected_text, replaces="", reason="")` | Change a loaded skill's instructions to match what the user wants |

### `audio` — `AudioToolsMixin`

Register with `register_audio_tools()`.

| Tool | Purpose |
|------|---------|
| `transcribe_media(file_path, language="", model="", output_path="", speakers=0)` | Transcribe an audio or video file and save it to a text file |
| `refine_transcript(transcript_path, output_path="")` | Label speakers and add timestamps to a raw transcript |
| `analyze_transcript(transcript_path, request, fields=None, output_path="")` | Find every matching item in a recording, with timestamps |
| `export_transcript(transcript_path, format="srt", output_path="")` | Write subtitles or text with timestamps |

### `audio_generation` — `AudioGenerationToolsMixin`

Call `init_audio_generation(output_dir=None)`; it registers the tools. Output goes to `<gaia home>/cache/audio/generations` by default.

| Tool | Purpose |
|------|---------|
| `list_audio_generation_models()` | List downloaded music and sound-effect generators |
| `generate_music(prompt, model="ACE-Step-Music", lyrics=None, vocal_language=None, duration=None, steps=None, seed=None)` | Generate WAV music; empty lyrics mean instrumental |
| `generate_sound_effect(prompt, model="ThinkSound-SFX", duration=None, steps=None, cfg=None, seed=None)` | Generate a WAV sound effect |

### `wait` — `WaitToolsMixin`

Register with `register_wait_tools()`.

| Tool | Purpose |
|------|---------|
| `sleep(seconds: float, reason: str = "")` | Wait up to 300 s, e.g. until a rate limit resets; ends early on Stop |

### `reasoning_effort` — `ReasoningEffortToolsMixin`

Register with `register_reasoning_effort_tools()`.

| Tool | Purpose |
|------|---------|
| `set_reasoning_effort(level: str, reason: str = "")` | Set `low`, `medium` or `high` reasoning for the rest of the request, on models that grade reasoning |
