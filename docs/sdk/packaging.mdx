# Application Packaging

<Note>
There is no `gaia package` command. Distribute an agent as a Python package
(see 14.3), expose it as a web API with `gaia api start`, or run it in the Agent
UI (`gaia chat --ui`, shell in `src/gaia/apps/webui/`). See the
[Agent UI SDK](/sdk/sdks/agent-ui).
</Note>

![Status](https://img.shields.io/badge/status-architecture_reference-blue)

**Detailed Spec:** [Agent UI SDK](/sdk/sdks/agent-ui)

**Purpose:** Package GAIA agents as standalone applications for distribution.

---

## 14.1 Web UI

The Agent UI is a browser app served by `gaia chat --ui` (backend in
`src/gaia/ui/`, frontend in `src/gaia/apps/webui/`). It runs the agents GAIA
discovers, so an agent packaged as in 14.3 appears there without extra work.

```python
from gaia.agents.base.agent import Agent
from gaia.agents.base.tools import tool

class MyAgent(Agent):
    """Custom agent for distribution."""

    def _get_system_prompt(self) -> str:
        return "You are a helpful assistant."

    def _register_tools(self):
        @tool
        def my_capability(query: str) -> dict:
            """Custom tool."""
            return {"result": f"Processed: {query}"}
```

## 14.2 Desktop App

The Electron shell around the Agent UI lives in `src/gaia/apps/webui/`, and the
desktop installer is described in the
[Desktop Installer Plan](/plans/desktop-installer). GAIA does not generate a
per-agent desktop app.

## 14.3 Deployment Patterns

```python
# pyproject.toml - Package your agent
[project]
name = "my-gaia-agent"
version = "1.0.0"
dependencies = ["amd-gaia>=0.14.0"]

[project.entry-points."gaia.agents"]
my-agent = "my_package.agent:MyAgent"

[project.scripts]
my-agent = "my_package.cli:main"

# After install, users can:
# 1. Import: from my_package.agent import MyAgent
# 2. CLI: my-agent "Do something"
# 3. API: the gaia.agents entry point makes MyAgent discoverable;
#         start the OpenAI-compatible server with `gaia api start`
```
