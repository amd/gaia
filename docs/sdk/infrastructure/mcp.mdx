---
title: "Expose an Agent through MCP"
description: "Implement an MCPAgent and serve its explicitly declared tools to an MCP client."
---

Use `MCPAgent` when another application should call tools your agent exposes.
To let an agent **consume** external MCP tools instead, use the
[MCP client SDK](/sdk/sdks/mcp). These are opposite directions of integration.

## Implement the three required methods

`MCPAgent` inherits the abstract `_register_tools()` method from `Agent` and adds
`get_mcp_tool_definitions()` and `execute_mcp_tool()`. Implement all three.
This complete example provides one read-only MCP tool; it makes no model request.

Save it as `word_count_mcp.py` in the Python environment from the
[quickstart](/quickstart). Install the MCP extra:

```bash
uv pip install "amd-gaia[mcp]"
```

```python
from gaia.agents.base.mcp_agent import MCPAgent
from gaia.mcp.agent_mcp_server import AgentMCPServer


class WordCountMCPAgent(MCPAgent):
    def _register_tools(self):
        # This example exposes MCP tools, not model-dispatched tools.
        return None

    def get_mcp_tool_definitions(self):
        return [{
            "name": "count_words",
            "description": "Count whitespace-separated words in text.",
            "inputSchema": {
                "type": "object",
                "properties": {"text": {"type": "string"}},
                "required": ["text"],
            },
        }]

    def execute_mcp_tool(self, tool_name, arguments):
        if tool_name != "count_words":
            raise ValueError(f"Unknown tool: {tool_name}")
        text = arguments.get("text")
        if not isinstance(text, str):
            raise ValueError("text must be a string")
        return {"count": len(text.split())}


if __name__ == "__main__":
    server = AgentMCPServer(
        agent_class=WordCountMCPAgent,
        host="127.0.0.1",
        port=8080,
        register_typed_tools=True,
        agent_params={"skip_lemonade": True, "silent_mode": True},
    )
    server.start()
```

```bash
uv run python word_count_mcp.py
```

The default transport is Streamable HTTP. Configure your MCP client with
`http://127.0.0.1:8080/mcp`, then call `count_words` with
`{"text": "GAIA runs locally"}`; the tool result contains `{"count": 3}`.
Stop the server with Ctrl+C. The host and port belong to this MCP server, not the
TUI control API or Lemonade.

## Understand the dispatch boundary

`AgentMCPServer` constructs the agent and registers the definitions returned by
`get_mcp_tool_definitions()`. With `register_typed_tools=True`, it derives typed
MCP wrappers from the declared schemas. The default is `False`, preserving the
older kwargs-envelope compatibility path.

Incoming tool requests call `execute_mcp_tool()` directly. They do not run through
`Agent.process_query()` or inherit its per-tool approval loop. Validate the
arguments and authorization appropriate to the host before adding mutating tools.
This example deliberately has no file, shell, or external-service operations.

Declaring optional prompts or resources on `MCPAgent` does not make
`AgentMCPServer` publish them: its registration path currently registers tools.
Keep the server integration aligned with the capabilities it actually exposes.

For stdio, the server also accepts `transport="stdio"`; host and port are ignored
for that transport. Keep diagnostic output off stdout because stdout carries MCP
messages. See the
[server source](https://github.com/amd/gaia/blob/main/src/gaia/mcp/agent_mcp_server.py)
for transport and wrapper behavior.

## Test before connecting a client

Import `WordCountMCPAgent` and construct it with `skip_lemonade=True`. Verify that
`execute_mcp_tool("count_words", {"text": "GAIA runs locally"})` returns a count of
3 and that unknown tools and non-string input fail. Then test discovery and a tool
call through a real MCP client; direct Python calls alone do not validate the wire
protocol.

See [agent testing](/sdk/testing) and [MCP setup](/integrations/mcp) for related
workflows.
