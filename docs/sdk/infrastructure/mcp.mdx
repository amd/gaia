## 8.1 MCP Agent Base

**Purpose:** Base class for Model Context Protocol compatible agents.

```python
from gaia.agents.base.mcp_agent import MCPAgent
from gaia.agents.base.tools import tool
from typing import List, Dict

class MyMCPAgent(MCPAgent):
    """Agent compatible with MCP protocol."""

    def get_mcp_tool_definitions(self) -> List[Dict]:
        """Return MCP-formatted tool definitions."""
        return [
            {
                "name": "search_database",
                "description": "Search the database for records",
                "inputSchema": {
                    "type": "object",
                    "properties": {
                        "query": {
                            "type": "string",
                            "description": "Search query"
                        },
                        "limit": {
                            "type": "integer",
                            "description": "Max results",
                            "default": 10
                        }
                    },
                    "required": ["query"]
                }
            }
        ]

    def execute_mcp_tool(self, tool_name: str, arguments: Dict) -> Dict:
        """Execute an MCP tool call."""
        if tool_name == "search_database":
            query = arguments["query"]
            limit = arguments.get("limit", 10)
            # Your implementation
            return {"results": [...], "count": 5}

        return {"error": f"Unknown tool: {tool_name}"}

    # Optional: Provide prompts
    def get_mcp_prompts(self) -> List[Dict]:
        return [
            {
                "name": "search_help",
                "description": "Help with database searches",
                "arguments": [
                    {"name": "topic", "description": "What to search for"}
                ]
            }
        ]

    # Optional: Expose resources
    def get_mcp_resources(self) -> List[Dict]:
        return [
            {
                "uri": "database://schema",
                "name": "Database Schema",
                "description": "Current database schema",
                "mimeType": "application/json"
            }
        ]
```

## 8.2 MCP Server

**Import:** `from gaia.mcp.agent_mcp_server import AgentMCPServer`

```python
from gaia.mcp.agent_mcp_server import AgentMCPServer
from my_package.agent import MyMCPAgent

# Create MCP server for your agent
server = AgentMCPServer(
    agent_class=MyMCPAgent,
    name="my-mcp-agent",
    port=8080,
    host="localhost",
    verbose=True,
    agent_params={"custom_param": "value"}
)

# Start server
server.start()

# Now accessible via MCP protocol
# VSCode, Claude Desktop, etc. can connect
```

## 8.3 Code Index MCP Server

**Import:** `from gaia.mcp.servers.code_index_mcp import CodeIndexService, create_code_index_mcp`

Exposes [`CodeIndexSDK`](https://github.com/amd/gaia/blob/main/src/gaia/code_index/sdk.py)
for one repository, so Claude Code, Cursor, or any MCP client can search the
code by meaning. Embeddings run on the local Lemonade Server; nothing leaves
the machine. Requires the `[mcp]` and `[rag]` extras.

From the CLI (stdio):

```bash
gaia mcp code-index --repo /path/to/repo

# Register it with Claude Code from inside the repository
claude mcp add gaia-code-index -- gaia mcp code-index --repo .
```

| Tool | Arguments | Returns |
|------|-----------|---------|
| `search_code` | `query`, `scope` (`"all"` or `"code"`, default `"all"`), `top_k` (1-50, default 10) | Ranked chunks with `file_path`, `start_line`, `end_line`, `symbol_name`, `symbol_type`, `language`, `score`, `content` |
| `get_index_status` | none | `indexed`, chunk and file counts, `embedding_model`, `rebuild_running`, and `progress` while a rebuild runs |
| `rebuild_index` | `max_files` (default 5000), `model` (Lemonade embedding model) | `files_indexed`, `chunks_created`, `duration_seconds`, and `chunks_dropped` with a warning when some chunks failed to embed |

The first `rebuild_index` embeds every file and can take minutes on a large
repository; later calls reuse unchanged files. Until an index exists,
`search_code` returns an error that says to call `rebuild_index`. Only one
rebuild runs at a time, and searches keep using the previous index while it
does. The server refuses to start on your home directory.

From Python:

```python
from gaia.code_index.sdk import CodeIndexConfig
from gaia.mcp.servers.code_index_mcp import CodeIndexService, create_code_index_mcp

service = CodeIndexService(CodeIndexConfig(repo_path="/path/to/repo"))
create_code_index_mcp(service).run(transport="stdio")
```
