## Use GAIA

Install the terminal application using the [Terminal UI guide](/guides/terminal-hub),
then run:

```bash
gaia-tui
```

The readiness screen identifies missing dependencies and offers supported setup
steps. For cloud chat, use the provider picker described in [AI providers](/guides/ai-providers).
For the browser or Electron application, see [Agent UI](/guides/agent-ui).

## Build your first agent

Install Python 3.10+ and [uv](https://docs.astral.sh/uv/), then create an environment:

```bash
uv venv
uv pip install amd-gaia
uv run gaia init
```

`gaia init` sets up the local Lemonade backend and models. It can download several
GB. The Python package and `gaia-tui` are separate installations.

Save this as `count_agent.py`. `Agent` is abstract: implement `_register_tools` on your subclass and customize `_get_system_prompt`
for its task.

```python
from gaia.agents.base.agent import Agent
from gaia.agents.base.tools import tool


class CountAgent(Agent):
    def _get_system_prompt(self) -> str:
        return "Use count_words to count words in the user's text. Report its result."

    def _register_tools(self):
        @tool
        def count_words(text: str) -> dict:
            """Count whitespace-separated words in text."""
            return {"count": len(text.split())}


agent = CountAgent()
result = agent.process_query("Count the words in: GAIA runs on my computer")
print(result["result"])
```

Run it with the local backend available:

```bash
uv run python count_agent.py
```

The tool computes the count; the model chooses the tool call and writes the answer.
See the [agent harness](/sdk/core/agent-system) for the result contract, lifecycle,
limits, and error handling, and [tools](/sdk/core/tools) for registration and permissions.
