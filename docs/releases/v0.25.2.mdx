# GAIA v0.25.2 Release Notes

## What's New

- **The Agent UI and the terminal UI tell you when an update is out** and install it only when you ask. Auto-update is a setting, off by default. (PR [#5730](https://github.com/amd/gaia/pull/5730))
- **The Agent UI streams GAIA's work as a live timeline** of its notes, steps and thinking. (PR [#5966](https://github.com/amd/gaia/pull/5966))
- **GAIA chats show what fills the context window**, and skills that work together now combine in one turn. (PRs [#5746](https://github.com/amd/gaia/pull/5746), [#5422](https://github.com/amd/gaia/pull/5422))
- **Start a new chat in a folder you pick** from its folder chip, rename a chat from its sidebar row, and search chats from the top of the sidebar. (PRs [#5826](https://github.com/amd/gaia/pull/5826), [#5961](https://github.com/amd/gaia/pull/5961), [#5828](https://github.com/amd/gaia/pull/5828), [#5868](https://github.com/amd/gaia/pull/5868))
- **Settings > Skills groups skills by where they came from**, and the file browser hides dot entries behind a Show hidden toggle. (PRs [#5830](https://github.com/amd/gaia/pull/5830), [#5834](https://github.com/amd/gaia/pull/5834))
- **A write request relayed from another window names where the file will land.** (PR [#5783](https://github.com/amd/gaia/pull/5783))

## Bug Fixes

A selection of the user-visible fixes; the full list is in the changelog below.

- **`gaia init` installs the GAIA agent even when Lemonade or model setup fails**, and the Windows installer keeps `%VARS%` in your user PATH. (PRs [#5802](https://github.com/amd/gaia/pull/5802), [#5809](https://github.com/amd/gaia/pull/5809))
- **An update replaces a running agent and restarts it.** The daemon no longer restarts mid-turn: one left on the previous release keeps running, with a notice, until `gaia daemon restart`. A crashed Lemonade check is reported as a failed check. (PRs [#5747](https://github.com/amd/gaia/pull/5747), [#5847](https://github.com/amd/gaia/pull/5847), [#5779](https://github.com/amd/gaia/pull/5779))
- **`gaia init` replaces a release candidate's agent build with the published one**, so final-release agent fixes reach people who updated from an RC. (PR [#5831](https://github.com/amd/gaia/pull/5831))
- **The desktop app waits on "Starting GAIA…" until the backend is listening**, reads the installed version without starting Python, and first-run setup shows the real state of this PC with the right model-server advice. (PRs [#5916](https://github.com/amd/gaia/pull/5916), [#5919](https://github.com/amd/gaia/pull/5919), [#5825](https://github.com/amd/gaia/pull/5825))
- **AMD LLM Gateway models answer right after GAIA starts Lemonade itself**, and the terminal UI checks a saved gateway default as a cloud model. (PRs [#5959](https://github.com/amd/gaia/pull/5959), [#5992](https://github.com/amd/gaia/pull/5992))
- **GAIA no longer reports Lemonade ready when the context-size re-check fails**, and cloud models no longer set the local context ceiling. (PRs [#5793](https://github.com/amd/gaia/pull/5793), [#5813](https://github.com/amd/gaia/pull/5813))
- **A request to run something now gets an answer back when nothing ran**, instead of silence. (PR [#5753](https://github.com/amd/gaia/pull/5753))
- **Claude models keep their reasoning across tool calls**, because thinking blocks are sent back with their tool turn. (PR [#5072](https://github.com/amd/gaia/pull/5072))
- **One malformed tool call no longer ends the turn** — non-object tool arguments are recovered. (PR [#5732](https://github.com/amd/gaia/pull/5732))
- **A turn bigger than the history budget, such as a pasted log, is kept in shortened form** instead of being dropped along with the turns before it. (PR [#5864](https://github.com/amd/gaia/pull/5864))
- **A write outside the chat's folders asks once** and names where the file lands, a relative file name lands in the chat's folder, and "my Documents" means your Documents folder. (PRs [#5815](https://github.com/amd/gaia/pull/5815), [#5861](https://github.com/amd/gaia/pull/5861), [#5844](https://github.com/amd/gaia/pull/5844))
- **Asking about a folder in your home folder, such as Videos, leads GAIA to ask for that folder** instead of saying it can't reach your home folder. (PR [#5822](https://github.com/amd/gaia/pull/5822))
- **Shell checks understand Windows paths with backslashes**, and `gh` repo names and API routes are no longer treated as file paths. (PRs [#5794](https://github.com/amd/gaia/pull/5794), [#5751](https://github.com/amd/gaia/pull/5751))
- **On macOS, the agent's shell sees your login PATH when GAIA is opened from Finder or the Dock**, so tools installed with Homebrew or similar are found. (PR [#5867](https://github.com/amd/gaia/pull/5867))
- **`run_python` runs in a scratch folder when the repo around it is not approved.** (PR [#5768](https://github.com/amd/gaia/pull/5768))
- **Content search accepts a single file and skips credential files without opening them**, and `read_file` reports a file's size on disk. (PRs [#5954](https://github.com/amd/gaia/pull/5954), [#5904](https://github.com/amd/gaia/pull/5904))
- **Text files saved in Windows ANSI (CP1252) open in `read_file` and in document search**, as do UTF-16 text files; unreadable Excel files give an actionable error and titled sheets read correctly. (PRs [#5766](https://github.com/amd/gaia/pull/5766), [#5761](https://github.com/amd/gaia/pull/5761), [#5812](https://github.com/amd/gaia/pull/5812))
- **Files with an uncommon extension can be found by name, and file search stays out of other apps' data on macOS.** (PRs [#5754](https://github.com/amd/gaia/pull/5754), [#5854](https://github.com/amd/gaia/pull/5854))
- **Free disk space is reported correctly**, without the agent detouring through a shell. (PR [#5849](https://github.com/amd/gaia/pull/5849))
- **Document indexing no longer overflows on dense tables, and vision-extracted blocks stay whole when a document is split into sections.** (PRs [#5742](https://github.com/amd/gaia/pull/5742), [#5817](https://github.com/amd/gaia/pull/5817))
- **A watched document stays indexed after a save on macOS**, a document with no pages is cited without a page number, and Agent SDK document Q&A sizes its context from the real window and reports retrieval failures. (PRs [#5836](https://github.com/amd/gaia/pull/5836), [#5903](https://github.com/amd/gaia/pull/5903), [#5810](https://github.com/amd/gaia/pull/5810))
- **Memory downloads a missing embedding model at startup** instead of running the whole session without memory, and that download can be cancelled. (PRs [#5863](https://github.com/amd/gaia/pull/5863), [#5979](https://github.com/amd/gaia/pull/5979))
- **PINs, card numbers and SSNs are kept out of memory and the chat log**, and ordinary lowercase file names are no longer masked. (PRs [#5690](https://github.com/amd/gaia/pull/5690), [#5913](https://github.com/amd/gaia/pull/5913), [#5998](https://github.com/amd/gaia/pull/5998))
- **A new chat no longer waits behind another chat's memory extraction**, the Memory page separates denied tool calls from failures, and memory searches with a date-only end date include that day. (PRs [#5799](https://github.com/amd/gaia/pull/5799), [#6001](https://github.com/amd/gaia/pull/6001), [#5818](https://github.com/amd/gaia/pull/5818))
- **Chat sessions are kept when saving fails**, instead of being lost. (PR [#5862](https://github.com/amd/gaia/pull/5862))
- **Agent UI chats** — a chat reopened or left mid-answer shows it live with Stop, a chat keeps streaming under the Scheduled tasks dialog, sent messages show attached images and file links, a failed attachment shows its reason, relayed GAIA turns list web sources and appear in Under the hood, and each turn has one progress timer. (PRs [#5944](https://github.com/amd/gaia/pull/5944), [#5898](https://github.com/amd/gaia/pull/5898), [#5936](https://github.com/amd/gaia/pull/5936), [#5943](https://github.com/amd/gaia/pull/5943), [#5941](https://github.com/amd/gaia/pull/5941), [#5946](https://github.com/amd/gaia/pull/5946), [#5949](https://github.com/amd/gaia/pull/5949), [#5824](https://github.com/amd/gaia/pull/5824))
- **Turn totals stay right** — a step that exits early keeps its tokens and time, and performance totals stay finite. (PRs [#5451](https://github.com/amd/gaia/pull/5451), [#5967](https://github.com/amd/gaia/pull/5967))
- **Privacy and access controls show their real state** — the Private button and new-chat chip, the per-chat Internet switch on GAIA chats, and Full access, which only "Turn it on" enables and Settings can turn off. (PRs [#5821](https://github.com/amd/gaia/pull/5821), [#5945](https://github.com/amd/gaia/pull/5945), [#5886](https://github.com/amd/gaia/pull/5886), [#5832](https://github.com/amd/gaia/pull/5832), [#5937](https://github.com/amd/gaia/pull/5937), [#5935](https://github.com/amd/gaia/pull/5935))
- **Agent UI follow-through** — a tool row waiting for your approval says so with no timer; an agent that stopped answering is not blamed on the model server; the model chip follows a switch made in another window; Review changes keeps a last line without a newline on its own row; always-on skills are labelled instead of offering Use; the oldest cached chat agents are evicted. (PRs [#5786](https://github.com/amd/gaia/pull/5786), [#5785](https://github.com/amd/gaia/pull/5785), [#5748](https://github.com/amd/gaia/pull/5748), [#5749](https://github.com/amd/gaia/pull/5749), [#5731](https://github.com/amd/gaia/pull/5731), [#5741](https://github.com/amd/gaia/pull/5741))

## Known Issues

- **The first chat after launching the desktop app can wait on "Waiting for the GPU" and never start** when a background task GAIA proposed for itself is holding the model. Restart the app to free it. Tracked in [#6006](https://github.com/amd/gaia/issues/6006).
- **An update doesn't restart the daemon on its own** — run `gaia daemon restart` after updating. Tracked in [#6026](https://github.com/amd/gaia/issues/6026).
- **Attaching an image on a PC that uses only AMD LLM Gateway models starts a ~5 GB vision-model download inside the turn**, which can take minutes while the screen says "Analyzing image". Run `gaia download --agent vlm` first so the download happens up front. Tracked in [#5990](https://github.com/amd/gaia/issues/5990).
- **The terminal UI lists a saved gateway default as a ~4 GB download when launched on a local model.** The label is wrong: gateway models run in the cloud and need no download, so skip it. Tracked in [#6016](https://github.com/amd/gaia/issues/6016).
- **A relayed GAIA turn can lose its final answer after you approve a prompt**, about one time in ten, and end with an error naming Lemonade. Send the message again. Tracked in [#6019](https://github.com/amd/gaia/issues/6019).
