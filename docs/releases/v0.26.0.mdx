# GAIA v0.26.0 Release Notes

## Breaking Changes

- **Dynamic tool loading is on by default, and its old settings are gone** — `GAIA_DYNAMIC_TOOLS_TAU` and `GAIA_DYNAMIC_TOOLS_MAX` no longer do anything, and a choice made under the old Beta toggle is not carried over. Turn it off with `gaia config set dynamic_tools false` or Settings → Advanced. (PR [#6449](https://github.com/amd/gaia/pull/6449))
- **The `use_chatgpt` and `use_openai` arguments are gone** — they only raised an error since the OpenAI and LiteLLM adapters were removed, and now Python reports an unexpected argument. Delete the argument and pick the model through Lemonade. `provider="openai"` and `--use-chatgpt` still explain the move. ([#7023](https://github.com/amd/gaia/issues/7023))
- **The `gaia-agent-chat` package is gone** — `ChatAgent` ships in the flagship package, so import it with `from gaia_agent.chat_agent import ChatAgent, ChatAgentConfig`. `ChatAgentLite` and `python -m gaia_agent_chat.app` were removed with it; use `gaia chat`. Sessions saved under the old `chat`, `doc` and `file` agents still reopen on GAIA, and a leftover `gaia-agent-chat` install is now ignored with a warning instead of taking those ids over. (Issue [#6103](https://github.com/amd/gaia/issues/6103))

## What's New

- **The first reply in a new chat is much faster** — chat starts on the most-used tools in short form and loads the rest at most once, and a new `search_tools` tool finds any tool or installed skill it missed. A long conversation also keeps its cache when a background job runs. (PR [#6449](https://github.com/amd/gaia/pull/6449))
- **Analyze long recordings and video links** — give GAIA an hour-long video, an audio file or a video link, from the CLI or the Agent UI, and get a timestamped, speaker-labelled transcript, a report, subtitles and answers, with a live progress card. (PR [#6451](https://github.com/amd/gaia/pull/6451))
- **Hear replies read aloud** — a speaker button on every Agent UI reply, and `/read-aloud` and `/voice` in the TUI. Voice, speed and "read every reply" are shared under Settings › Read aloud. (PR [#6489](https://github.com/amd/gaia/pull/6489))
- **See what the PC is doing while GAIA answers** — every chat shows a strip with CPU, memory, each GPU, the NPU and the network, with a minute of history. On Windows the numbers match Task Manager. (PR [#6548](https://github.com/amd/gaia/pull/6548))
- **See what a cloud model has cost** — the composer shows this chat's and today's spend while a priced cloud model is in use; click it for a per-answer breakdown. (PR [#6775](https://github.com/amd/gaia/pull/6775))
- **Save a problem report when a model call fails** — the error names a local report you can save from the failed answer or Settings → Privacy and attach to a bug. Nothing is sent anywhere, and the report never holds your message text. (PR [#6665](https://github.com/amd/gaia/pull/6665))
- **Use GAIA on stock GNOME without a tray extension** — closing the window minimizes GAIA to the dock with the model still loaded, and the dock's Quit stops it. (PR [#6868](https://github.com/amd/gaia/pull/6868))
- **Use a Lemonade on another computer** — the install guide covers the three steps on the server computer. (PR [#6865](https://github.com/amd/gaia/pull/6865))

## Bug Fixes

- **Asking about an image no longer demands a Gemma download** when another tested image-reading model is already on disk. (PR [#6825](https://github.com/amd/gaia/pull/6825))
- **A Python snippet that fails on a missing library says how to retry with the standard library**, and later chats remember what worked. (PR [#6828](https://github.com/amd/gaia/pull/6828))
- **Averages the model works out by hand after a failed computation are checked** and flagged when wrong. (PR [#6831](https://github.com/amd/gaia/pull/6831))
- **An edit sent twice in one turn no longer damages the file** — the second, identical edit is refused. (PR [#6844](https://github.com/amd/gaia/pull/6844))
- **An agent left running for days on macOS keeps answering** — the OS temp cleaner no longer deletes its unpacked files. (PR [#6851](https://github.com/amd/gaia/pull/6851))
- **Another GAIA process can no longer load a model onto the NPU while a stopped reply is still draining.** (PR [#6821](https://github.com/amd/gaia/pull/6821))
- **`gaia schedule --sink notification` works on Windows.** (PR [#6503](https://github.com/amd/gaia/pull/6503))
- **A Fireworks key from `FIREWORKS_API_KEY` is no longer copied into the keychain**, and it takes precedence over an older saved key. (PR [#6811](https://github.com/amd/gaia/pull/6811))
- **The invented-figure check catches amounts written like `2,708.95 USD` or `2,708.95 dollars`.** (PR [#6817](https://github.com/amd/gaia/pull/6817))
- **The planted-instruction warning catches look-alike, zero-width and hyphenated AI addresses.** (PR [#6837](https://github.com/amd/gaia/pull/6837))
- **Stored memories can no longer imitate the per-turn memory footer.** (PR [#6843](https://github.com/amd/gaia/pull/6843))
- **On Gemma 4 E4B, three email tools that the compact tier cannot use are withheld.** (PR [#6842](https://github.com/amd/gaia/pull/6842))
- **Failed Agent UI turns are reported as errors over MCP**, not as completed turns. (PR [#6819](https://github.com/amd/gaia/pull/6819))
- **A web fetch that hits a rate-limit wait on a redirect no longer times out** — the wait is no longer charged to the fetch deadline. (PR [#6857](https://github.com/amd/gaia/pull/6857))
- **The email agent's published API contract lists its full `/v1/email/agent/*` surface.** (PR [#6200](https://github.com/amd/gaia/pull/6200))
- **`gaia eval` corpus generation fails on files the manifest does not declare**, instead of passing silently. (PR [#6869](https://github.com/amd/gaia/pull/6869))
- **Docs corrections** for the Windows setup steps, the memory categories and the eval scenario example. (PRs [#6852](https://github.com/amd/gaia/pull/6852), [#6864](https://github.com/amd/gaia/pull/6864), [#6863](https://github.com/amd/gaia/pull/6863))
