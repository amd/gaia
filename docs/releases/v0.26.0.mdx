# GAIA v0.26.0 Release Notes

## Summary

- A new chat answers sooner, and follow-up turns stay cached.
- GAIA reads and sends Gmail, manages Google and Outlook calendars, analyzes long recordings and video links, and answers Discord messages.
- A model server that is down or restarting is reported in one plain sentence, and open chats keep working after a restart.
- Chats no longer leave MCP server processes behind, and credential files stay closed to scripts.
- The terminal UI is now `gaia-cli`; see Breaking Changes.
- 23 contributors merged 815 PRs and closed 726 issues since v0.25.4.

## Breaking Changes

- **The terminal UI is now `gaia-cli`, and `gaia-cli` no longer means the Python command** — its old name was `gaia-tui`. Updating installs `gaia-cli`; the one-line installer keeps `gaia-tui` working, and the Windows setup and macOS and Linux packages remove it. A script that ran the Python CLI as `gaia-cli` should call `gaia`. (PRs [#7492](https://github.com/amd/gaia/pull/7492), [#8367](https://github.com/amd/gaia/pull/8367))
- **Dynamic tool loading is on by default, and its old settings are gone** — `GAIA_DYNAMIC_TOOLS_TAU` and `GAIA_DYNAMIC_TOOLS_MAX` do nothing, and a choice made under the old Beta toggle is not carried over. Turn it off with `gaia config set dynamic_tools false`. (PR [#6449](https://github.com/amd/gaia/pull/6449))
- **The `use_chatgpt` and `use_openai` arguments are gone** — delete them and pick the model through Lemonade. (Issue [#7023](https://github.com/amd/gaia/issues/7023))
- **The `gaia-agent-chat` package is gone** — import `ChatAgent` with `from gaia_agent.chat_agent import ChatAgent, ChatAgentConfig`; `ChatAgentLite` is removed, so use `gaia chat`. Old sessions still reopen on GAIA. (Issue [#6103](https://github.com/amd/gaia/issues/6103))

## What's New

- **Faster first replies** — chat starts on the most-used tools and loads the rest once, and follow-up turns stay cached. (PRs [#6449](https://github.com/amd/gaia/pull/6449), [#5039](https://github.com/amd/gaia/pull/5039), [#7150](https://github.com/amd/gaia/pull/7150))
- **Gmail and calendar from the flagship** — draft, reply, forward and send Gmail with approval, plus Google and Outlook calendar tools. (PRs [#6479](https://github.com/amd/gaia/pull/6479), [#6485](https://github.com/amd/gaia/pull/6485), [#7164](https://github.com/amd/gaia/pull/7164))
- **Analyze long recordings and video links** — a timestamped, speaker-labelled transcript, report and subtitles, from the CLI or the Agent UI. (PR [#6451](https://github.com/amd/gaia/pull/6451))
- **Message GAIA from Discord** — DM your own bot, and set reminders, alerts and triggers it runs on its own. (PRs [#6786](https://github.com/amd/gaia/pull/6786), [#7144](https://github.com/amd/gaia/pull/7144), [#6887](https://github.com/amd/gaia/pull/6887), [#6886](https://github.com/amd/gaia/pull/6886))
- **Hear replies read aloud** — a speaker button on every Agent UI reply. (PR [#6489](https://github.com/amd/gaia/pull/6489))
- **See what is happening** — a live CPU, memory, GPU, NPU and network strip in every chat, cloud spend in the composer, and every log in the Agent UI. (PRs [#6548](https://github.com/amd/gaia/pull/6548), [#6775](https://github.com/amd/gaia/pull/6775), [#6664](https://github.com/amd/gaia/pull/6664))
- **Edit a sent message, try an answer again, continue a stopped one**, and reopen past sessions in the TUI. (PRs [#7459](https://github.com/amd/gaia/pull/7459), [#7465](https://github.com/amd/gaia/pull/7465), [#7165](https://github.com/amd/gaia/pull/7165))
- **Skills** — add one by pasting a link, get suggestions for unloaded skills, and use three new ones: report-from-sources, log-triage and meeting-actions. (PRs [#5803](https://github.com/amd/gaia/pull/5803), [#5423](https://github.com/amd/gaia/pull/5423), [#5421](https://github.com/amd/gaia/pull/5421))
- **Models** — a `hybrid` choice sends each turn to a cheaper or a stronger model, and Muse Glimmer 30B is an opt-in local model. (PRs [#8196](https://github.com/amd/gaia/pull/8196), [#7168](https://github.com/amd/gaia/pull/7168))
- **Documents in more languages** — Arabic, Japanese, Chinese and Cyrillic files read correctly, and a damaged UTF-8 file is refused instead of garbled. (PRs [#8024](https://github.com/amd/gaia/pull/8024), [#8230](https://github.com/amd/gaia/pull/8230), [#8296](https://github.com/amd/gaia/pull/8296))
- **Safer by default** — project guidance loads only after asking once per folder, and Undo puts back files a script moved. (PRs [#6965](https://github.com/amd/gaia/pull/6965), [#8128](https://github.com/amd/gaia/pull/8128))

Upgrade with:

```bash
pip install --upgrade amd-gaia
```

## Bug Fixes

A reference list, most user-visible first. Every merged change is in the changelog below.

### Model server and chats

- **Open chats keep working after the model server restarts** — GAIA keeps its own server's key across a restart. (PRs [#8366](https://github.com/amd/gaia/pull/8366), [#8162](https://github.com/amd/gaia/pull/8162))
- **Deleting a chat stops its MCP servers, and never starts or restarts the agent.** (PRs [#8364](https://github.com/amd/gaia/pull/8364), [#8380](https://github.com/amd/gaia/pull/8380))
- **MCP server processes are no longer left behind on every new chat.** (PR [#8298](https://github.com/amd/gaia/pull/8298))
- **A failed MCP server no longer shows "Connected"**, and a missing Node.js or uv is named instead of a transport error. (PRs [#8273](https://github.com/amd/gaia/pull/8273), [#8365](https://github.com/amd/gaia/pull/8365), [#8163](https://github.com/amd/gaia/pull/8163))
- **A document taken off a chat is no longer read** — its access is revoked and searches skip it. (PRs [#8375](https://github.com/amd/gaia/pull/8375), [#8025](https://github.com/amd/gaia/pull/8025), [#8160](https://github.com/amd/gaia/pull/8160))
- **A model server that isn't answering gets one plain wording everywhere**, appears without a reload, and is translated. (PRs [#7576](https://github.com/amd/gaia/pull/7576), [#7789](https://github.com/amd/gaia/pull/7789), [#8259](https://github.com/amd/gaia/pull/8259), [#8235](https://github.com/amd/gaia/pull/8235), [#7833](https://github.com/amd/gaia/pull/7833))
- **A document added at launch waits for GAIA's model server.** (PR [#8304](https://github.com/amd/gaia/pull/8304))
- **A failed turn names the cause and offers Settings, not a command**; long errors are cut at a word. (PRs [#7729](https://github.com/amd/gaia/pull/7729), [#8276](https://github.com/amd/gaia/pull/8276))
- **An agent crash offers the agent's log**, not the model server's. (PR [#8359](https://github.com/amd/gaia/pull/8359))
- **A sidecar shuts down when its daemon is killed**, and the daemon restarts if left on another model server. (PRs [#8306](https://github.com/amd/gaia/pull/8306), [#8075](https://github.com/amd/gaia/pull/8075))
- **An unreachable custom Lemonade URL is named**, not called "not installed". (PRs [#8122](https://github.com/amd/gaia/pull/8122), [#8066](https://github.com/amd/gaia/pull/8066))
- **A cloud turn that failed before any reply is not billed.** (PR [#8321](https://github.com/amd/gaia/pull/8321))
- **A model switch loads the model and carries the chat over.** (PR [#7590](https://github.com/amd/gaia/pull/7590))
- **The TUI says when GAIA stopped mid-answer.** (PR [#8309](https://github.com/amd/gaia/pull/8309))

## Known Issues

- **NPU PCs: chat on the NPU profile returns an empty reply**, and the embedder falls back to GGUF — use the GPU/CPU profile for now. Tracked in [#6008](https://github.com/amd/gaia/issues/6008).
- **Fedora 44: setup cannot reach any HTTPS site**, so it can neither connect a cloud model nor download one — tracked in [#7226](https://github.com/amd/gaia/issues/7226).
- **Long sessions on Windows: Lemonade's bundled llama-server leaks handles on every request** until the model server restarts — restart it from time to time. An upstream Lemonade issue, tracked in [#8312](https://github.com/amd/gaia/issues/8312).
- **Coding: editing a requested config or data file, or a skill's `SKILL.md`, does not mark an earlier "tests pass" as stale** — re-run the tests after such an edit. Tracked in [#8213](https://github.com/amd/gaia/issues/8213).
- **Your own model server, stopped: the connection banner says it is "not installed"** and suggests `gaia init` — start your server again. Tracked in [#8313](https://github.com/amd/gaia/issues/8313).
- **Summarizing a 1,000+ page document can time out** — ask about sections or page ranges instead. Tracked in [#8218](https://github.com/amd/gaia/issues/8218).
- **Attached files lose the spaces in their names**, so `team meeting notes.wav` becomes `team_meeting_notes.wav` — rename the file before attaching if the name matters. Tracked in [#8361](https://github.com/amd/gaia/issues/8361).
