# GAIA v0.25.1 Release Notes

This release needs GAIA agent 0.3.1, which new installs get. With an older agent, private and memory-off chats stop with an update message instead of saving to memory, and Full access still can't open the folders you name.

## Breaking Changes

- **The `ChatSDK`, `ChatConfig`, `ChatResponse` and `ChatSession` aliases are removed** — import `AgentSDK`, `AgentConfig`, `AgentResponse` and `AgentSession`, their names since v0.20.0. (PR [#5366](https://github.com/amd/gaia/pull/5366))

## What's New

- **Each chat shows where it runs and what it changed** — a session panel lists the folders it may use, an internet switch, its outputs and every file it changed, and a rail beside each answer lists its sources and the files it wrote. (PRs [#5326](https://github.com/amd/gaia/pull/5326), [#5246](https://github.com/amd/gaia/pull/5246))
- **Undo a turn's file changes** — **Review changes** shows the diff; **Undo this turn** restores every file, even after a restart. (PR [#5239](https://github.com/amd/gaia/pull/5239))
- **A turn's work reads in plain words** — a live plan checklist and one line per tool call replace raw tool cards. (PRs [#5245](https://github.com/amd/gaia/pull/5245), [#5269](https://github.com/amd/gaia/pull/5269))
- **See what fills the context window and where the time goes**, type while GAIA works, and retry an answer with another model. (PRs [#5275](https://github.com/amd/gaia/pull/5275), [#5241](https://github.com/amd/gaia/pull/5241))
- **Chats that need you come first** — chats wait their turn for the GPU, and a tray icon shows whether GAIA is working or waiting on you. (PRs [#5242](https://github.com/amd/gaia/pull/5242), [#5354](https://github.com/amd/gaia/pull/5354))
- **The model picker shows where each model runs and whether it fits this PC**; cloud models show their price before you pick one, with an optional monthly limit. (PRs [#5244](https://github.com/amd/gaia/pull/5244), [#5270](https://github.com/amd/gaia/pull/5270))
- **gpt-oss 20B and 120B are supported local models** where they fit. (PRs [#5356](https://github.com/amd/gaia/pull/5356), [#5374](https://github.com/amd/gaia/pull/5374), [#5357](https://github.com/amd/gaia/pull/5357))
- **A new look** — a frameless desktop window, eight color palettes, and new type and motion that reduced motion turns off. (PRs [#5312](https://github.com/amd/gaia/pull/5312), [#5290](https://github.com/amd/gaia/pull/5290), [#5266](https://github.com/amd/gaia/pull/5266))
- **First-run setup names the chat model and its download size** up front. (PR [#5240](https://github.com/amd/gaia/pull/5240))
- **Lemonade Server v2026.43.3.** (PRs [#5148](https://github.com/amd/gaia/pull/5148), [#5558](https://github.com/amd/gaia/pull/5558))

## Bug Fixes

A selection of the user-visible fixes; the full list is in the changelog below.

- **Full access opens the folders you name in the desktop app** — it used to refuse them, often without asking. Ask mode shows Allow/Deny. (PR [#5414](https://github.com/amd/gaia/pull/5414))
- **Private and memory-off chats in the desktop app no longer save memories**, and relayed chats show their cost and the full details of a permission prompt. (PR [#5418](https://github.com/amd/gaia/pull/5418))
- **A reply cut short by a restart says so** — the Agent UI shows it as interrupted instead of an unanswered question, a resumed TUI session records it the same way, and a document caught mid-index shows **Failed** with **Retry**. (PRs [#5386](https://github.com/amd/gaia/pull/5386), [#5390](https://github.com/amd/gaia/pull/5390))
- **Esc closes a dialog without stopping the answer.** (PR [#5433](https://github.com/amd/gaia/pull/5433))
- **A rejected cloud key names the fix for the app you are in**, and files already saved are listed as saved. (PR [#5440](https://github.com/amd/gaia/pull/5440))
- **A turn the model gave up on is marked failed, not done**, with what ran and what is unfinished. (PR [#5432](https://github.com/amd/gaia/pull/5432))
- **Ctrl+C on a TUI one-shot stops the agent's turn too.** (PR [#5435](https://github.com/amd/gaia/pull/5435))
- **The desktop app survives an agent that died**, and quitting stops every process it started. (PR [#5438](https://github.com/amd/gaia/pull/5438))
- **Web search keeps working when DuckDuckGo rate-limits** — it retries, tries the lite endpoint, and uses Tavily if you connected it. (PR [#5434](https://github.com/amd/gaia/pull/5434))
- **"Undo may be incomplete" appears only when a snippet or script may have written files**, and names what ran. (PR [#5436](https://github.com/amd/gaia/pull/5436))
- **GAIA stops only a Lemonade Server it started itself.** (PR [#5439](https://github.com/amd/gaia/pull/5439))
- **A long turn that overflows the context window recovers** — the overflow check looks only at the agent's own model, and the retry keeps older tool results one call away instead of dropping them. (PRs [#5219](https://github.com/amd/gaia/pull/5219), [#5396](https://github.com/amd/gaia/pull/5396))
- **Chats and apps sharing one model server wait their turn** instead of failing, evicting each other's model, or reporting a busy server as stopped. (PRs [#5321](https://github.com/amd/gaia/pull/5321), [#5328](https://github.com/amd/gaia/pull/5328), [#5336](https://github.com/amd/gaia/pull/5336), [#5337](https://github.com/amd/gaia/pull/5337), [#5314](https://github.com/amd/gaia/pull/5314), [#5317](https://github.com/amd/gaia/pull/5317), [#5264](https://github.com/amd/gaia/pull/5264))
- **Closing one TUI session no longer stops the model server for every other session.** (PR [#5282](https://github.com/amd/gaia/pull/5282))
- **A PC that sleeps mid-answer no longer wakes to a stall error.** (PR [#5387](https://github.com/amd/gaia/pull/5387))
- **A failed turn is never re-run behind your back**, so its tools don't run twice. (PR [#5338](https://github.com/amd/gaia/pull/5338))
- **Memory keeps only what you say about yourself**, brings it up when a question is about it, stays current as facts change, and refuses corrupted entries. (PRs [#5243](https://github.com/amd/gaia/pull/5243), [#5324](https://github.com/amd/gaia/pull/5324), [#5395](https://github.com/amd/gaia/pull/5395), [#5306](https://github.com/amd/gaia/pull/5306))
- **A stuck MCP server, web fetch, media decode or chat bridge no longer hangs the turn**, and document indexing has limits and a working Cancel. (PRs [#5346](https://github.com/amd/gaia/pull/5346), [#5384](https://github.com/amd/gaia/pull/5384), [#5383](https://github.com/amd/gaia/pull/5383), [#5382](https://github.com/amd/gaia/pull/5382), [#5339](https://github.com/amd/gaia/pull/5339))
- **Settings and shared state survive several GAIA processes at once** — config writes, the file index and connector tokens are no longer lost or deleted. (PRs [#5388](https://github.com/amd/gaia/pull/5388), [#5377](https://github.com/amd/gaia/pull/5377), [#5378](https://github.com/amd/gaia/pull/5378))
- **GAIA no longer closes your own PowerPoint or ngrok tunnels.** (PRs [#5345](https://github.com/amd/gaia/pull/5345), [#5376](https://github.com/amd/gaia/pull/5376))
- **Scheduled tasks show runs missed while the PC was off**, run in windows that cross midnight, and recover after a crash. (PRs [#5391](https://github.com/amd/gaia/pull/5391), [#5407](https://github.com/amd/gaia/pull/5407), [#5380](https://github.com/amd/gaia/pull/5380))
- **A custom model downloads on its first chat**, can be picked in the Agent UI once downloaded, and is no longer reloaded before every turn. (PRs [#5360](https://github.com/amd/gaia/pull/5360), [#5449](https://github.com/amd/gaia/pull/5449), [#5362](https://github.com/amd/gaia/pull/5362))
- **A missing file is reported as not found instead of asking you to approve it**, and a download asks about the file, not its folder. (PRs [#5307](https://github.com/amd/gaia/pull/5307), [#5308](https://github.com/amd/gaia/pull/5308))
- **Your own scripts get 600 s instead of being killed at 30 s.** (PR [#5347](https://github.com/amd/gaia/pull/5347))
- **One bad batch of parallel tool calls no longer ends the turn with no answer.** (PR [#5413](https://github.com/amd/gaia/pull/5413))
- **`gaia install --lemonade` checks the installer's size and SHA-256 before running it**, for every supported installer. (PRs [#5389](https://github.com/amd/gaia/pull/5389), [#5455](https://github.com/amd/gaia/pull/5455))
- **Model servers left behind by a crashed Lemonade are stopped**, so the next start doesn't load the same models twice. (PR [#5352](https://github.com/amd/gaia/pull/5352))
- **The GAIA agent starts on Ubuntu 22.04, Debian 12 and RHEL 9** — it needed glibc 2.38 and failed at launch. (PR [#5545](https://github.com/amd/gaia/pull/5545))
- **Intel Macs can install GAIA again**, with `install.sh`, `pip install amd-gaia` and the `[rag]` and `[ui]` extras. (PRs [#5546](https://github.com/amd/gaia/pull/5546), [#5481](https://github.com/amd/gaia/pull/5481))
- **Settings load from a folder Windows lets you read but not create files in**, and GAIA operations waiting on a shared file take turns in order instead of timing out at random. (PR [#5469](https://github.com/amd/gaia/pull/5469))
- **A permission prompt left unanswered in one chat no longer blocks every other chat**, and chats on a cloud model don't wait for the GPU. (PR [#5609](https://github.com/amd/gaia/pull/5609))
- **A Full access chat in the desktop app asks before a command that needs approval** instead of refusing it. (PR [#5562](https://github.com/amd/gaia/pull/5562))
- **Documents from the library reach new chats**, and answers from documents are no longer saved as facts about you. (PR [#5540](https://github.com/amd/gaia/pull/5540))
- **The desktop app says when first-run setup failed** instead of opening as ready, and its crash dialog restarts or quits instead of leaving a dead window. (PRs [#5598](https://github.com/amd/gaia/pull/5598), [#5537](https://github.com/amd/gaia/pull/5537))
- **`gaia uninstall --purge` removes GAIA's memory, sessions, config and agent**, and lists what it keeps. (PR [#5602](https://github.com/amd/gaia/pull/5602))
- **`gaia download` finds GAIA's own Lemonade Server** instead of reporting downloaded models as missing. (PR [#5590](https://github.com/amd/gaia/pull/5590))
