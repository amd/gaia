# GAIA v0.27.0 Release Notes

## Summary

- Connect more than one Google or Microsoft account, and manage each one separately.
- GAIA desktop has a browser beside the chat that both you and GAIA can use.
- Type `/` and a skill's name to run that skill on a request.
- New skills build and check Office files and triage logs.
- The standalone email agent is gone; the main GAIA agent handles mail.
- Quitting GAIA desktop frees the model's memory.
- 9 contributors merged 119 PRs and closed 135 issues since v0.26.0.

## Breaking Changes

- **The standalone email agent is removed** — `gaia email`, the `gaia-agent-email` and `@amd-gaia/agent-email` packages, the `/v1/email` routes and the `email` setup profile are gone. Ask GAIA about your mail in `gaia chat` or the Agent UI instead; it reads, drafts and sends through the Google and Microsoft connectors, as the [Email guide](/guides/email) describes. On upgrade the old install is removed, and any email it had scheduled is named once, since it won't be sent. (PR [#7108](https://github.com/amd/gaia/pull/7108))
- **`gaia agent list` and `gaia eval benchmark` are removed** — GAIA ships one agent, and `gaia agent list` now says what replaced it. (PR [#7108](https://github.com/amd/gaia/pull/7108))
- **`gaia.ui.email_sidecar` is renamed `gaia.ui.sidecar`** — update the import. (PR [#7108](https://github.com/amd/gaia/pull/7108))

## What's New

- **Several accounts per mail provider** — `gaia connectors connect google --add` adds another account; Settings and the terminal UI list each one with its own Reconnect, Make default and Disconnect. (PRs [#8331](https://github.com/amd/gaia/pull/8331), [#8332](https://github.com/amd/gaia/pull/8332), [#8333](https://github.com/amd/gaia/pull/8333))
- **Browser pane in GAIA desktop** — browse beside the chat while GAIA reads and drives the same tab. (PR [#5973](https://github.com/amd/gaia/pull/5973))
- **Run a skill by name** — start a message with `/skill-name` in the Agent UI, terminal UI, `gaia -p` or the API; typing `/` lists installed skills. (PR [#8483](https://github.com/amd/gaia/pull/8483))
- **Office documents and reports** — the `office-docs` skill builds spreadsheets, decks and Word files and checks formulas for wrong cell references; `report-from-sources` reads named series from a folder's spreadsheets, citing each value's cell. (PRs [#5417](https://github.com/amd/gaia/pull/5417), [#5453](https://github.com/amd/gaia/pull/5453))
- **Log triage** — the `log-triage` skill's `triage_logs` tool reads every named log in one call and returns the anomalies, bursts, hosts and affected ids. (PRs [#5465](https://github.com/amd/gaia/pull/5465), [#8537](https://github.com/amd/gaia/pull/8537))
- **Skill auto-load, opt-in** — with `GAIA_SKILL_AUTOLOAD=1` a skill that clearly matches the request loads before the turn. Off by default. (PRs [#5442](https://github.com/amd/gaia/pull/5442), [#8510](https://github.com/amd/gaia/pull/8510))
- **Document reranking, opt-in** — `RAGConfig(enable_reranking=True)` reorders retrieved passages with a downloaded Lemonade reranking model. (PR [#6136](https://github.com/amd/gaia/pull/6136))
- **Review saved folder answers** — `gaia trust` lists, adds, declines and forgets GAIA's per-folder answers about project guidance files. (PR [#8480](https://github.com/amd/gaia/pull/8480))
- **Sign in to Gmail over SSH** — `gaia connectors connect google --callback-port PORT` fixes the port so it can be forwarded. (PR [#8474](https://github.com/amd/gaia/pull/8474))
- **Settings reach open chats** — a model server, connector or skill change applies on an open chat's next message. (PR [#8400](https://github.com/amd/gaia/pull/8400))
- **Agent UI** — Ctrl+/ lists keyboard shortcuts, formulas render instead of LaTeX source, the library shows which chats use each document, a scheduled task can be edited in place with its past runs listed, and connector setup is shown as numbered steps. (PRs [#7504](https://github.com/amd/gaia/pull/7504), [#7499](https://github.com/amd/gaia/pull/7499), [#7514](https://github.com/amd/gaia/pull/7514), [#7527](https://github.com/amd/gaia/pull/7527), [#8281](https://github.com/amd/gaia/pull/8281), [#8279](https://github.com/amd/gaia/pull/8279), [#8280](https://github.com/amd/gaia/pull/8280))
- **Scripted `gaia -p` runs** — `--disallowed-tools`, `--no-web` and `--no-skills` withhold tools; a run uses the apps' model and its whole `--time-limit`, and the agent knows nobody is there to answer. (PRs [#8326](https://github.com/amd/gaia/pull/8326), [#7808](https://github.com/amd/gaia/pull/7808), [#8385](https://github.com/amd/gaia/pull/8385), [#8451](https://github.com/amd/gaia/pull/8451))
- **Large tool results pass by handle** — a tool given an `output_…` handle gets the full result without it entering the prompt. (PR [#8121](https://github.com/amd/gaia/pull/8121))

## Bug Fixes

- **Quitting GAIA desktop frees the model** — idle agents stop and the chat model unloads within seconds; another open GAIA app or a running `gaia` command still keeps it loaded. Closes [#8504](https://github.com/amd/gaia/issues/8504). (PR [#8511](https://github.com/amd/gaia/pull/8511))
- **One embedder per PC, on the GPU**, shown in Settings › Memory, so a chat on another device no longer clears memory's search index. NPU embedding is shown but can't be chosen yet. (PR [#8368](https://github.com/amd/gaia/pull/8368))
- **Long tasks keep their time and answers** — the agent runs a saved script by path, a time limit holds back less, `read_file` reads .pptx slides, .html text and long workbooks by sheet, and a reused scratch table reports its existing rows. (PR [#8536](https://github.com/amd/gaia/pull/8536))
- **Reading an image no longer unloads another session's chat model.** (PR [#8509](https://github.com/amd/gaia/pull/8509))
- **Hidden sensitive memories stay hidden in Memory › Advanced**, including from the editor, tooltips and expanded rows. (PR [#8518](https://github.com/amd/gaia/pull/8518))
- **A file search that finds nothing names the folders it searched.** (PR [#8515](https://github.com/amd/gaia/pull/8515))
- **`gaia api` keeps accepting requests on Windows after a client hangs up early.** (PR [#8519](https://github.com/amd/gaia/pull/8519))

## Known Issues

- **Installed builds: `gaia -p` refuses `--time-limit`, `--disallowed-tools`, `--no-web` and `--no-skills`**, because there the agent runs through GAIA's background service — run without them, or from a developer install that includes the agent package. Tracked in [#8495](https://github.com/amd/gaia/issues/8495).
- **NPU PCs: chat on the NPU profile returns an empty reply** — use the GPU/CPU profile for now. Tracked in [#6008](https://github.com/amd/gaia/issues/6008).
- **Fedora 44: setup cannot reach any HTTPS site**, so it can neither connect a cloud model nor download one — tracked in [#7226](https://github.com/amd/gaia/issues/7226).
- **Long sessions on Windows: Lemonade's bundled llama-server leaks handles on every request** — restart the model server from time to time. Tracked in [#8312](https://github.com/amd/gaia/issues/8312).
- **Coding: editing a config, data or `SKILL.md` file does not mark an earlier "tests pass" as stale** — re-run the tests after such an edit. Tracked in [#8213](https://github.com/amd/gaia/issues/8213).
- **Your own model server, stopped: the connection banner says it is "not installed"** — start your server again. Tracked in [#8313](https://github.com/amd/gaia/issues/8313).
- **Summarizing a 1,000+ page document can time out** — ask about sections or page ranges instead. Tracked in [#8218](https://github.com/amd/gaia/issues/8218).
