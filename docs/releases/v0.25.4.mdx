# GAIA v0.25.4 Release Notes

## What's New

- **Use the Agent UI in Arabic, and ask about Arabic, English or mixed documents in either language** — the interface runs fully right to left, answers follow the language of the question, and citations open the document at the cited page. Arabic PDFs keep their numbers and Latin terms when indexed. (PR [#6165](https://github.com/amd/gaia/pull/6165))
- **Keep every AI request on this PC** — `gaia config set network_policy local_ai_only` refuses any request to a cloud model before it is sent, across chat, agents, documents, speech, the Agent UI, the terminal UI and web search. (PR [#5956](https://github.com/amd/gaia/pull/5956))
- **Index screenshots, receipts and scanned pages** — PNG, JPG, WebP, BMP, GIF and TIFF files are read with the vision model when you pick or drop them. (PR [#5651](https://github.com/amd/gaia/pull/5651))
- **The GAIA agent reads whole email threads and finds mail waiting on your reply**, in Gmail and Outlook, still read-only. (PR [#6124](https://github.com/amd/gaia/pull/6124))
- **Add to this reply and Always allow work with the GAIA agent** — a message sent mid-answer reaches the running turn, and "Always allow" grants are listed and revocable per chat and in Settings. (PR [#5541](https://github.com/amd/gaia/pull/5541))
- **Start new chats in full access from Settings › Permissions**, after confirming a warning. (PR [#5827](https://github.com/amd/gaia/pull/5827))
- **Skills can carry their own tools into the release build**, gated like the core tools they resemble. (PRs [#5450](https://github.com/amd/gaia/pull/5450), [#5454](https://github.com/amd/gaia/pull/5454))
- **Install the Agent UI on your phone** — over mobile access it adds to the home screen and opens full screen, and the mobile access dialog gives the Safari and Chrome steps. (PRs [#6329](https://github.com/amd/gaia/pull/6329), [#6342](https://github.com/amd/gaia/pull/6342))
- **Generated images, music and sound effects appear in the chat**, with a player for audio, and are still there when you reopen it. (PR [#6384](https://github.com/amd/gaia/pull/6384))
- **See what a chat's agent can do** — the session panel's Agent info lists its tools, grouped by where they come from. (PR [#6381](https://github.com/amd/gaia/pull/6381))
- **Connect Slack** from Settings › Connectors with a bot token, then grant it to the agents that may read your channels, threads and DMs. (PR [#6370](https://github.com/amd/gaia/pull/6370))
- **Make several independent attempts at a hard task** — `gaia -p "<prompt>" --attempts N` (up to 4) runs each attempt in its own copy of the folder, then one turn combines them. (PR [#6313](https://github.com/amd/gaia/pull/6313))
- **Schedule a prompt to run once** — `gaia schedule add --at` takes a time or a delay like `+2h`, and runs on the next start if the daemon was down. (PR [#6382](https://github.com/amd/gaia/pull/6382))
- **Run any registered agent from the terminal** with `gaia chat --agent <id>`. (PR [#6333](https://github.com/amd/gaia/pull/6333))
- **Use GAIA's code search from Claude Code, Cursor or any MCP client** — `gaia mcp code-index --repo <path>`. Code search now also covers Verilog, SystemVerilog and VHDL. (PRs [#6369](https://github.com/amd/gaia/pull/6369), [#6346](https://github.com/amd/gaia/pull/6346))
- **For developers** — an opt-in image-variations tool, a RAG option that indexes each record of a JSON array separately, image generation and transcription through the generic LLM client, and an SPDX SBOM for the C++ framework. (PRs [#6365](https://github.com/amd/gaia/pull/6365), [#6364](https://github.com/amd/gaia/pull/6364), [#6357](https://github.com/amd/gaia/pull/6357), [#6323](https://github.com/amd/gaia/pull/6323))
- **The Agent UI no longer adds an "Example Agent" to every agent list**; unedited copies are removed. (PR [#6123](https://github.com/amd/gaia/pull/6123))

## Bug Fixes

- **Document search stays fast on large libraries** — a search no longer re-reads every indexed chunk, and removing a document no longer re-embeds the rest. (PRs [#6406](https://github.com/amd/gaia/pull/6406), [#6320](https://github.com/amd/gaia/pull/6320))
- **Indexing a folder picks up Word, PowerPoint and Excel files**, like indexing them one at a time, and lists each skipped file with a reason. (PR [#6314](https://github.com/amd/gaia/pull/6314))
- **A failed reply says why in plain words and offers Try again**, which resends the question. (PR [#6354](https://github.com/amd/gaia/pull/6354))
- **An approved file edit shows its diff** in the Agent UI and the terminal UI. (PR [#6325](https://github.com/amd/gaia/pull/6325))
- **Signing in to Google or Microsoft from the browser allows 15 minutes instead of 2**, and an expired link says so. Google is asked for the same permissions however you connect. (PRs [#6359](https://github.com/amd/gaia/pull/6359), [#6343](https://github.com/amd/gaia/pull/6343))
- **A follow-up about an email thread in the Agent UI reads the thread found earlier**, `gaia email autonomy status` shows what the last cycle did, and `gaia email autonomy run` waits for the cycle to finish. (PRs [#6379](https://github.com/amd/gaia/pull/6379), [#6373](https://github.com/amd/gaia/pull/6373))
- **Mobile access without ngrok shows a one-time setup step** with the install command and a Retry button, not an error. (PR [#6322](https://github.com/amd/gaia/pull/6322))
- **The desktop app offers a safe start after three crashes in a row**: try again, open the log folder, or quit. (PR [#6306](https://github.com/amd/gaia/pull/6306))
- **Shell commands that change system settings ask first** even when their names look read-only, such as setting the clock or releasing the network. Writing `GAIA.md` keeps a backup like other file writes. (PRs [#6337](https://github.com/amd/gaia/pull/6337), [#6352](https://github.com/amd/gaia/pull/6352))
- **The verification line no longer says tests passed when the agent only printed an old test log**, an agent that recovered from an error stops marking later answers failed, and a long recalled procedure is no longer cut mid-step and presented as complete. (PRs [#6374](https://github.com/amd/gaia/pull/6374), [#6362](https://github.com/amd/gaia/pull/6362), [#6334](https://github.com/amd/gaia/pull/6334))
- **Code search tells you to re-index when its index is inconsistent**, instead of returning nothing or unrelated code. (PR [#6330](https://github.com/amd/gaia/pull/6330))
- **MCP servers that check the connection handshake now connect.** (PR [#6367](https://github.com/amd/gaia/pull/6367))
- **Restarting the daemon stops every agent process the last one left running**, and `gaia daemon start-agent` refuses to run a binary other than the one your checkout pins. (PRs [#6304](https://github.com/amd/gaia/pull/6304), [#6349](https://github.com/amd/gaia/pull/6349))
- **Approving a rejected, cancelled or finished goal no longer puts it back in the queue.** (PR [#6340](https://github.com/amd/gaia/pull/6340))
- **Terminal UI** — `gaia-tui run` no longer offers keys after it has exited and delivers its cancel before quitting, a long agent session keeps only the end of its error output, and settings are read under the same lock they are saved with. (PRs [#6327](https://github.com/amd/gaia/pull/6327), [#6309](https://github.com/amd/gaia/pull/6309), [#6350](https://github.com/amd/gaia/pull/6350))
- **The C++ agent shows the server's error** instead of "no tokens", and its memory stays flat on long queries. (PRs [#6317](https://github.com/amd/gaia/pull/6317), [#6331](https://github.com/amd/gaia/pull/6331))
- **Flags that did nothing are rejected** — `gaia email --debug` and `--stats`, and `gaia api start --step-through`. (PRs [#6311](https://github.com/amd/gaia/pull/6311), [#6328](https://github.com/amd/gaia/pull/6328))
- **`gaia agent export` leaves out compiled bytecode**, and `gaia cache status` calls the Context7 service optional rather than unavailable. (PR [#6339](https://github.com/amd/gaia/pull/6339))
- **Agent evals are harder to fool** — a task that reads the answer key fails, `gaia eval benchmark` names a context overflow instead of scoring 0%, `--compare` counts a slower PASS→FAIL as a regression and warns when scenarios were replaced, `--fix` refuses uncommitted changes and stops on a failed fix, and `--generate-corpus` no longer overwrites the sales data. (PRs [#6368](https://github.com/amd/gaia/pull/6368), [#6358](https://github.com/amd/gaia/pull/6358), [#6305](https://github.com/amd/gaia/pull/6305), [#6353](https://github.com/amd/gaia/pull/6353), [#6335](https://github.com/amd/gaia/pull/6335), [#6345](https://github.com/amd/gaia/pull/6345))
- **Judged evals and corpus generation use your Claude Code login**, and an `ANTHROPIC_API_KEY` found only in a `.env` file no longer overrides it. (PRs [#6378](https://github.com/amd/gaia/pull/6378), [#6363](https://github.com/amd/gaia/pull/6363))
- **A release can no longer publish with a desktop installer missing or an agent's version files out of step**, and the hub rejects an artifact named like one of its own per-version docs. (PRs [#6356](https://github.com/amd/gaia/pull/6356), [#6355](https://github.com/amd/gaia/pull/6355), [#6302](https://github.com/amd/gaia/pull/6302))
- **A chat you start is no longer stuck on "Waiting for the GPU"** behind a background task GAIA proposed for itself. (PR [#6096](https://github.com/amd/gaia/pull/6096))
- **"Save it to my Documents folder" writes to your Documents folder**, not GAIA's hidden one, and shell, code search, watched folders and saved audio, screenshot and download paths use the chat's folder. (PRs [#6074](https://github.com/amd/gaia/pull/6074), [#6069](https://github.com/amd/gaia/pull/6069))
- **Adding a document again after moving it updates its location**, instead of leaving chats pointing at the old, missing file. (PR [#6177](https://github.com/amd/gaia/pull/6177))
- **One chat indexing large documents no longer blocks other chats from starting.** (PR [#6171](https://github.com/amd/gaia/pull/6171))
- **A repo picked with `index_codebase` is remembered on the next turn.** (PR [#6056](https://github.com/amd/gaia/pull/6056))
- **A context window you set deliberately small is kept**, and a GPU that reports an implausible amount of VRAM no longer picks an unsafe one. (PRs [#6152](https://github.com/amd/gaia/pull/6152), [#6150](https://github.com/amd/gaia/pull/6150))
- **Chats get a topic title while their first answer runs** on a cloud model, and a failed title is retried on later turns. (PRs [#5972](https://github.com/amd/gaia/pull/5972), [#6174](https://github.com/amd/gaia/pull/6174))
- **Two Agent UI processes starting together no longer race on a chat-database upgrade**, the email and chat databases retry their setup, and a locked database waits its timeout once and names the file. (PRs [#6151](https://github.com/amd/gaia/pull/6151), [#6044](https://github.com/amd/gaia/pull/6044), [#6054](https://github.com/amd/gaia/pull/6054))
- **Undo is offered after a turn that changed files and then errored**, and a reply that only ran read-only commands like `ls` no longer warns that Undo can't restore files. (PRs [#6083](https://github.com/amd/gaia/pull/6083), [#6120](https://github.com/amd/gaia/pull/6120))
- **The terminal UI says when it is older than the installed GAIA**, with a download link. (PR [#6141](https://github.com/amd/gaia/pull/6141))
- **`gaia-desktop` runs from a terminal after installing the `.deb`.** (PR [#6131](https://github.com/amd/gaia/pull/6131))
- **Outlook unread listings work.** (PR [#6119](https://github.com/amd/gaia/pull/6119))
- **"Remind me tomorrow" no longer promises an alert GAIA can't deliver**, and a memory setting that fails to save says so instead of reporting success. (PRs [#6127](https://github.com/amd/gaia/pull/6127), [#6081](https://github.com/amd/gaia/pull/6081))
- **Data questions about a workbook read every sheet**, not just the first, so a balance sheet on sheet two is found. (PR [#6130](https://github.com/amd/gaia/pull/6130))
- **`gaia -p ""` fails straight away with a clear message** instead of hanging when the prompt variable is empty. (PR [#6168](https://github.com/amd/gaia/pull/6168))
- **Document summaries follow the style you asked for**, and the data profile no longer offers web and media tools it doesn't have. (PRs [#6057](https://github.com/amd/gaia/pull/6057), [#6053](https://github.com/amd/gaia/pull/6053))
- **The flagship agent wheel ships its starter skills.** (PR [#6080](https://github.com/amd/gaia/pull/6080))
- **Importing `gaia` no longer reconfigures the host program's logging.** (PR [#5951](https://github.com/amd/gaia/pull/5951))
- **Ctrl+D or Ctrl+C at the agent import prompt answers "no"** instead of crashing. (PR [#6140](https://github.com/amd/gaia/pull/6140))
- **Docs** — fixed broken `amd-gaia.ai` links, replaced the retired `--bypass-permissions` with `--full-access`, corrected the guides index, custom-agent, skills, eval and `/query` contract pages, synced the CLI reference with the parser, and added setup pages for the Git and Memory connectors. (PRs [#6066](https://github.com/amd/gaia/pull/6066), [#6129](https://github.com/amd/gaia/pull/6129), [#6147](https://github.com/amd/gaia/pull/6147), [#6146](https://github.com/amd/gaia/pull/6146), [#6145](https://github.com/amd/gaia/pull/6145), [#6133](https://github.com/amd/gaia/pull/6133), [#6134](https://github.com/amd/gaia/pull/6134), [#6135](https://github.com/amd/gaia/pull/6135), [#6137](https://github.com/amd/gaia/pull/6137), [#6113](https://github.com/amd/gaia/pull/6113), [#6310](https://github.com/amd/gaia/pull/6310), [#6324](https://github.com/amd/gaia/pull/6324), [#6319](https://github.com/amd/gaia/pull/6319), [#6332](https://github.com/amd/gaia/pull/6332), [#6308](https://github.com/amd/gaia/pull/6308))

## Known Issues

- **Attaching an image on a PC that uses only AMD LLM Gateway models starts a ~5 GB vision-model download inside the turn.** Run `gaia download --agent vlm` first so the download happens up front. Tracked in [#5990](https://github.com/amd/gaia/issues/5990).
- **A relayed GAIA turn can lose its final answer after you approve a prompt**, about one time in ten. It says the step didn't run; send the message again. Tracked in [#6019](https://github.com/amd/gaia/issues/6019).
