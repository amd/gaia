# GAIA v0.25.4 Release Notes

## Breaking Changes

- **On Gemma 4 E4B, the GAIA agent no longer offers data tables, email, image generation or the skill hub** — it asks you to switch to a larger model, which keeps them. (PR [#5892](https://github.com/amd/gaia/pull/5892))
- **Telegram no longer answers edited messages**, and `gaia.utils.pdf_page_to_image` raises `PdfRenderError` instead of returning `None`. (PR [#6197](https://github.com/amd/gaia/pull/6197))
- **GAIA requires Lemonade 2026.44.1** — it refuses an older server and names both versions; GAIA's own Lemonade upgrades in place. (PR [#6490](https://github.com/amd/gaia/pull/6490))

## What's New

- **Use the Agent UI in Arabic, and ask about Arabic, English or mixed documents in either language** — the interface runs right to left and citations open the document at the cited page. (PR [#6165](https://github.com/amd/gaia/pull/6165))
- **Keep every AI request on this PC** — `gaia config set network_policy local_ai_only` refuses any cloud model request before it is sent. (PR [#5956](https://github.com/amd/gaia/pull/5956))
- **Run GAIA's Gemma on the Ryzen AI NPU** and leave the GPU free — the model lists offer it where it fits, and `gaia init --profile npu` makes it the default. (PR [#5892](https://github.com/amd/gaia/pull/5892))
- **Guided first-run setup in the app and terminal UI**, re-runnable from Settings — it lists each model's size and fit before downloading, and on integrated-GPU PCs helps change the GPU's memory share. (PRs [#5638](https://github.com/amd/gaia/pull/5638), [#6241](https://github.com/amd/gaia/pull/6241), [#6256](https://github.com/amd/gaia/pull/6256), [#6268](https://github.com/amd/gaia/pull/6268), [#6228](https://github.com/amd/gaia/pull/6228), [#6271](https://github.com/amd/gaia/pull/6271))
- **Install skills from the hub with no setup** — bundled skills are published signed, so `gaia skill install <name>` works. (PR [#6235](https://github.com/amd/gaia/pull/6235))
- **Claude on the AMD LLM Gateway reuses cached prompts**, calls tools natively from the first request, and Claude models follow a repository's `CLAUDE.md`, `AGENTS.md` and skills. (PRs [#6217](https://github.com/amd/gaia/pull/6217), [#6298](https://github.com/amd/gaia/pull/6298), [#5964](https://github.com/amd/gaia/pull/5964))
- **Updates install in the background**, and the desktop app and terminal UI can go back from a bad update. (PR [#6446](https://github.com/amd/gaia/pull/6446))
- **Install the Agent UI on your phone** from mobile access. (PRs [#6329](https://github.com/amd/gaia/pull/6329), [#6342](https://github.com/amd/gaia/pull/6342))
- **The GAIA agent reads text aloud**; speech, images, music and sound effects play in the chat. Image generation works with TheNoise and other Lemonade image models. (PRs [#6204](https://github.com/amd/gaia/pull/6204), [#6511](https://github.com/amd/gaia/pull/6511), [#6384](https://github.com/amd/gaia/pull/6384), [#6047](https://github.com/amd/gaia/pull/6047))
- **Index screenshots, receipts and scanned pages** with the vision model, and **read whole email threads** and mail waiting on your reply in Gmail and Outlook. (PRs [#5651](https://github.com/amd/gaia/pull/5651), [#6124](https://github.com/amd/gaia/pull/6124))
- **Connect Slack or Discord** from Settings › Connectors and grant each to the agents you choose. (PRs [#6370](https://github.com/amd/gaia/pull/6370), [#6372](https://github.com/amd/gaia/pull/6372))
- **See what is available** — the session panel lists the chat's tools, and Settings lists every loaded model. (PRs [#6381](https://github.com/amd/gaia/pull/6381), [#6288](https://github.com/amd/gaia/pull/6288))
- **Chat controls** — Add to this reply and Always allow work with the GAIA agent, and new chats can start in full access from Settings › Permissions. (PRs [#5541](https://github.com/amd/gaia/pull/5541), [#5827](https://github.com/amd/gaia/pull/5827))
- **From the terminal** — `gaia -p --attempts N` combines up to 4 independent attempts, `gaia schedule add --at` runs a prompt once at a time or after a delay like `+2h`, and `gaia chat --agent <id>` runs any registered agent. (PRs [#6313](https://github.com/amd/gaia/pull/6313), [#6382](https://github.com/amd/gaia/pull/6382), [#6333](https://github.com/amd/gaia/pull/6333))
- **Use GAIA's code search from Claude Code, Cursor or any MCP client** with `gaia mcp code-index --repo <path>`; it also covers Verilog, SystemVerilog and VHDL. (PRs [#6369](https://github.com/amd/gaia/pull/6369), [#6346](https://github.com/amd/gaia/pull/6346))
- **For developers** — skills can ship their own tools, plus opt-in image-variation and image-to-3D (TRELLIS) tools, per-record JSON indexing, image and transcription calls on the generic LLM client, and an SPDX SBOM for the C++ framework. (PRs [#5450](https://github.com/amd/gaia/pull/5450), [#5454](https://github.com/amd/gaia/pull/5454), [#6365](https://github.com/amd/gaia/pull/6365), [#6267](https://github.com/amd/gaia/pull/6267), [#6364](https://github.com/amd/gaia/pull/6364), [#6357](https://github.com/amd/gaia/pull/6357), [#6323](https://github.com/amd/gaia/pull/6323))
