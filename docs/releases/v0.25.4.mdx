# GAIA v0.25.4 Release Notes

## Breaking Changes

- **On Gemma 4 E4B, the GAIA agent no longer offers data tables, email, image generation or the skill hub** — it asks you to switch to a larger model for those, and larger models keep them. (PR [#5892](https://github.com/amd/gaia/pull/5892))
- **Telegram no longer answers edited messages**, and `gaia.utils.pdf_page_to_image` raises `PdfRenderError` instead of returning `None`. (PR [#6197](https://github.com/amd/gaia/pull/6197))

## What's New

- **Use the Agent UI in Arabic, and ask about Arabic, English or mixed documents in either language** — the interface runs right to left and citations open the document at the cited page. (PR [#6165](https://github.com/amd/gaia/pull/6165))
- **Keep every AI request on this PC** — `gaia config set network_policy local_ai_only` refuses any cloud model request before it is sent. (PR [#5956](https://github.com/amd/gaia/pull/5956))
- **Run GAIA's Gemma on the Ryzen AI NPU** and leave the GPU free — the model lists offer it where it fits, and `gaia init --profile npu` makes it the default. (PR [#5892](https://github.com/amd/gaia/pull/5892))
- **Choose what first-run setup downloads** — the Agent UI and terminal UI list each model's size and whether it fits before downloading, and on integrated-GPU PCs show and help change the GPU's memory share. (PRs [#6241](https://github.com/amd/gaia/pull/6241), [#6256](https://github.com/amd/gaia/pull/6256), [#6268](https://github.com/amd/gaia/pull/6268), [#6228](https://github.com/amd/gaia/pull/6228), [#6271](https://github.com/amd/gaia/pull/6271))
- **Install skills from the hub with no setup** — releases publish the bundled skills signed with a key GAIA trusts, so `gaia skill install <name>` works. (PR [#6235](https://github.com/amd/gaia/pull/6235))
- **Claude on the AMD LLM Gateway reuses cached prompts**, calls tools natively from the first request, and Claude models follow a repository's `CLAUDE.md`, `AGENTS.md` and skills. (PRs [#6217](https://github.com/amd/gaia/pull/6217), [#6298](https://github.com/amd/gaia/pull/6298), [#5964](https://github.com/amd/gaia/pull/5964))
- **Install the Agent UI on your phone** from mobile access; the dialog gives the Safari and Chrome steps. (PRs [#6329](https://github.com/amd/gaia/pull/6329), [#6342](https://github.com/amd/gaia/pull/6342))
- **Generated images, music and sound effects appear in the chat**, and image generation works with TheNoise and other image models downloaded in Lemonade. (PRs [#6384](https://github.com/amd/gaia/pull/6384), [#6047](https://github.com/amd/gaia/pull/6047))
- **Index screenshots, receipts and scanned pages** with the vision model, and **read whole email threads** and mail waiting on your reply in Gmail and Outlook. (PRs [#5651](https://github.com/amd/gaia/pull/5651), [#6124](https://github.com/amd/gaia/pull/6124))
- **Connect Slack** from Settings › Connectors and grant it to the agents that may read your channels, threads and DMs. (PR [#6370](https://github.com/amd/gaia/pull/6370))
- **See what is available** — Agent info in the session panel lists the chat's tools, and Settings' Model server panel lists every loaded model. (PRs [#6381](https://github.com/amd/gaia/pull/6381), [#6288](https://github.com/amd/gaia/pull/6288))
- **Chat controls** — Add to this reply and Always allow work with the GAIA agent, and new chats can start in full access from Settings › Permissions. (PRs [#5541](https://github.com/amd/gaia/pull/5541), [#5827](https://github.com/amd/gaia/pull/5827))
- **From the terminal** — `gaia -p --attempts N` makes up to 4 independent attempts and combines them, `gaia schedule add --at` runs a prompt once at a time or after a delay like `+2h`, and `gaia chat --agent <id>` runs any registered agent. (PRs [#6313](https://github.com/amd/gaia/pull/6313), [#6382](https://github.com/amd/gaia/pull/6382), [#6333](https://github.com/amd/gaia/pull/6333))
- **Use GAIA's code search from Claude Code, Cursor or any MCP client** with `gaia mcp code-index --repo <path>`; it now also covers Verilog, SystemVerilog and VHDL. (PRs [#6369](https://github.com/amd/gaia/pull/6369), [#6346](https://github.com/amd/gaia/pull/6346))
- **For developers** — skills can ship their own tools, opt-in image-variation and image-to-3D (TRELLIS) tools, JSON arrays indexed as separate records, image generation and transcription on the generic LLM client, and an SPDX SBOM for the C++ framework. (PRs [#5450](https://github.com/amd/gaia/pull/5450), [#5454](https://github.com/amd/gaia/pull/5454), [#6365](https://github.com/amd/gaia/pull/6365), [#6267](https://github.com/amd/gaia/pull/6267), [#6364](https://github.com/amd/gaia/pull/6364), [#6357](https://github.com/amd/gaia/pull/6357), [#6323](https://github.com/amd/gaia/pull/6323))
- **The Agent UI no longer adds an "Example Agent" to every agent list.** (PR [#6123](https://github.com/amd/gaia/pull/6123))

## Bug Fixes

- **Document search is faster and finds what a document contains** — it ranks every chunk in any language, no longer re-reads every chunk per search, reuses a finished index when a chat opens the same file, and removing a document no longer re-embeds the rest. (PRs [#6260](https://github.com/amd/gaia/pull/6260), [#6406](https://github.com/amd/gaia/pull/6406), [#6262](https://github.com/amd/gaia/pull/6262), [#6320](https://github.com/amd/gaia/pull/6320))
- **Document indexing** — folders pick up Word, PowerPoint and Excel files, scanned pages stay readable and use a vision model the PC has, failures and evicted documents are named, and the context-size warning no longer fires during indexing. (PRs [#6314](https://github.com/amd/gaia/pull/6314), [#6261](https://github.com/amd/gaia/pull/6261), [#6159](https://github.com/amd/gaia/pull/6159), [#6223](https://github.com/amd/gaia/pull/6223), [#6184](https://github.com/amd/gaia/pull/6184), [#6258](https://github.com/amd/gaia/pull/6258))
- **Arabic** — numbers in Arabic PDFs stay beside the right words, answers follow the question's language more often, the right-to-left layout is fixed, and the remaining English labels are translated or muted. (PRs [#6257](https://github.com/amd/gaia/pull/6257), [#6287](https://github.com/amd/gaia/pull/6287), [#6188](https://github.com/amd/gaia/pull/6188), [#6266](https://github.com/amd/gaia/pull/6266), [#6264](https://github.com/amd/gaia/pull/6264))
- **Attaching an image no longer starts a hidden ~5 GB download** — GAIA says which vision model is missing. (PR [#6198](https://github.com/amd/gaia/pull/6198))
- **A model you set up in Lemonade with your own llama.cpp options loads with them**, instead of crashing on every turn. (PR [#6234](https://github.com/amd/gaia/pull/6234))
- **Gateway and cloud models** — DeepSeek on the gateway no longer carries ~12K tokens of tool schemas per call, a recovered turn no longer fails with HTTP 400, and a Fireworks outage no longer deletes a working key. (PRs [#6216](https://github.com/amd/gaia/pull/6216), [#6272](https://github.com/amd/gaia/pull/6272), [#6281](https://github.com/amd/gaia/pull/6281), [#6163](https://github.com/amd/gaia/pull/6163))
- **A failed reply says why in plain words and offers Try again**, and an approved file edit shows its diff in the Agent UI and terminal UI. (PRs [#6354](https://github.com/amd/gaia/pull/6354), [#6325](https://github.com/amd/gaia/pull/6325))
- **Asked for a slide, the agent builds a .pptx or HTML file**, and image generation reports success only when a real image was saved. (PR [#5977](https://github.com/amd/gaia/pull/5977))
- **A chat you start is no longer stuck on "Waiting for the GPU"**, one chat indexing no longer blocks others, and updating GAIA no longer interrupts an Agent UI turn. (PRs [#6096](https://github.com/amd/gaia/pull/6096), [#6171](https://github.com/amd/gaia/pull/6171), [#6195](https://github.com/amd/gaia/pull/6195))
- **File paths** — "Save it to my Documents folder" writes there, tools use the chat's folder, and a moved document is followed when added again. (PRs [#6074](https://github.com/amd/gaia/pull/6074), [#6069](https://github.com/amd/gaia/pull/6069), [#6177](https://github.com/amd/gaia/pull/6177))
- **Signing in to Google or Microsoft from the browser allows 15 minutes instead of 2**, an expired link says so, and a crash mid-save no longer deletes a working connection. (PRs [#6359](https://github.com/amd/gaia/pull/6359), [#6343](https://github.com/amd/gaia/pull/6343), [#6176](https://github.com/amd/gaia/pull/6176))
- **Email** — follow-ups in the Agent UI read the thread found earlier, `gaia email autonomy status` shows the last cycle, `autonomy run` waits for it, waiting-on-you alerts skip auto-replies and CC-only mail, and Outlook unread listings work. (PRs [#6379](https://github.com/amd/gaia/pull/6379), [#6373](https://github.com/amd/gaia/pull/6373), [#6189](https://github.com/amd/gaia/pull/6189), [#6119](https://github.com/amd/gaia/pull/6119))
- **Mobile access without ngrok shows a one-time setup step**, and the desktop app offers a safe start after three crashes in a row. (PRs [#6322](https://github.com/amd/gaia/pull/6322), [#6306](https://github.com/amd/gaia/pull/6306))
- **Shell commands that change system settings ask first** even when their names look read-only, and writing `GAIA.md` keeps a backup. (PRs [#6337](https://github.com/amd/gaia/pull/6337), [#6352](https://github.com/amd/gaia/pull/6352))
- **Honest status** — the verification line no longer counts a printed test log as a test run, a recovered agent stops marking later answers failed, a long recalled procedure is no longer cut mid-step, and failed session saves and memory settings say so. (PRs [#6374](https://github.com/amd/gaia/pull/6374), [#6362](https://github.com/amd/gaia/pull/6362), [#6334](https://github.com/amd/gaia/pull/6334), [#6280](https://github.com/amd/gaia/pull/6280), [#6081](https://github.com/amd/gaia/pull/6081))
- **Code search** — a repo picked with `index_codebase` is remembered, an inconsistent index asks you to re-index, and a missing FAISS fails before embedding. (PRs [#6056](https://github.com/amd/gaia/pull/6056), [#6330](https://github.com/amd/gaia/pull/6330), [#6203](https://github.com/amd/gaia/pull/6203))
- **Context and storage** — a deliberately small context window is kept, implausible VRAM reports are ignored, and concurrent starts no longer race or over-wait on the databases or split the turn log. (PRs [#6152](https://github.com/amd/gaia/pull/6152), [#6150](https://github.com/amd/gaia/pull/6150), [#6151](https://github.com/amd/gaia/pull/6151), [#6044](https://github.com/amd/gaia/pull/6044), [#6054](https://github.com/amd/gaia/pull/6054), [#6295](https://github.com/amd/gaia/pull/6295))
- **Daemon** — a restart stops every agent process left running, `start-agent` refuses a binary other than your checkout's pin, and an isolated `GAIA_HOME` no longer imports `~/.gaia`'s memory. (PRs [#6304](https://github.com/amd/gaia/pull/6304), [#6349](https://github.com/amd/gaia/pull/6349), [#6126](https://github.com/amd/gaia/pull/6126))
- **Terminal UI** — settings saves and reads share a lock with the Agent UI, it says when it is out of date, setup and `/models` report progress correctly, terminal-only installs get a usable remedy, and `gaia-tui run` delivers its cancel before exiting. (PRs [#6269](https://github.com/amd/gaia/pull/6269), [#6350](https://github.com/amd/gaia/pull/6350), [#6141](https://github.com/amd/gaia/pull/6141), [#6285](https://github.com/amd/gaia/pull/6285), [#6213](https://github.com/amd/gaia/pull/6213), [#6327](https://github.com/amd/gaia/pull/6327), [#6309](https://github.com/amd/gaia/pull/6309), [#6167](https://github.com/amd/gaia/pull/6167))
- **Chats get a topic title while their first answer runs**, Undo stays available after an error turn, and Settings stays reachable through startup status blips with its close button in view. (PRs [#5972](https://github.com/amd/gaia/pull/5972), [#6174](https://github.com/amd/gaia/pull/6174), [#6083](https://github.com/amd/gaia/pull/6083), [#6120](https://github.com/amd/gaia/pull/6120), [#6215](https://github.com/amd/gaia/pull/6215), [#6190](https://github.com/amd/gaia/pull/6190))
- **Scheduled runs count the daylight-saving hour correctly**, approving a finished goal no longer re-queues it, and "Remind me tomorrow" no longer promises an alert GAIA can't deliver. (PRs [#6293](https://github.com/amd/gaia/pull/6293), [#6340](https://github.com/amd/gaia/pull/6340), [#6127](https://github.com/amd/gaia/pull/6127))
- **Web pages** — a rate-limited page tells the agent how long to wait, and a missed exact phrase still returns the relevant passage. (PRs [#6116](https://github.com/amd/gaia/pull/6116), [#6185](https://github.com/amd/gaia/pull/6185))
- **Commands** — `gaia -p ""` fails fast, `gaia telegram stop --force` stops the adapter, `gaia uninstall --venv` works from the venv on Windows, `gaia agent export` drops bytecode, and flags that did nothing (`gaia email --debug`/`--stats`, `gaia api start --step-through`) are rejected. (PRs [#6168](https://github.com/amd/gaia/pull/6168), [#6279](https://github.com/amd/gaia/pull/6279), [#6273](https://github.com/amd/gaia/pull/6273), [#6339](https://github.com/amd/gaia/pull/6339), [#6311](https://github.com/amd/gaia/pull/6311), [#6328](https://github.com/amd/gaia/pull/6328), [#6140](https://github.com/amd/gaia/pull/6140))
- **Data and documents** — workbook questions read every sheet, summaries follow the style you asked for, and profiles advertise only tools they have. (PRs [#6130](https://github.com/amd/gaia/pull/6130), [#6057](https://github.com/amd/gaia/pull/6057), [#6053](https://github.com/amd/gaia/pull/6053), [#6153](https://github.com/amd/gaia/pull/6153))
- **MCP servers that check the connection handshake now connect**, a hub agent that crashes on start says why, timed-out skill programs stop their child processes, and the C++ agent shows the server's error with flat memory on long queries. (PRs [#6367](https://github.com/amd/gaia/pull/6367), [#6224](https://github.com/amd/gaia/pull/6224), [#6317](https://github.com/amd/gaia/pull/6317), [#6331](https://github.com/amd/gaia/pull/6331), [#6173](https://github.com/amd/gaia/pull/6173))
- **Packaging** — GAIA no longer ships AGPL or GPL code, so PDFs are read with pypdfium2 and a damaged or password-protected PDF fails with an error instead of indexing blank; third-party notices ship inside every download; `gaia-desktop` runs after installing the `.deb`; the flagship wheel ships its starter skills; importing `gaia` leaves the host's logging alone. (PRs [#6197](https://github.com/amd/gaia/pull/6197), [#6290](https://github.com/amd/gaia/pull/6290), [#6131](https://github.com/amd/gaia/pull/6131), [#6080](https://github.com/amd/gaia/pull/6080), [#5951](https://github.com/amd/gaia/pull/5951))
- **Agent evals are harder to fool** — reading the answer key fails a task, a context overflow is named instead of scored 0%, `--compare` counts a slower PASS→FAIL and flags replaced scenarios, `--fix` refuses uncommitted changes, `--generate-corpus` leaves the sales data alone, and judged runs use your Claude Code login. (PRs [#6368](https://github.com/amd/gaia/pull/6368), [#6358](https://github.com/amd/gaia/pull/6358), [#6305](https://github.com/amd/gaia/pull/6305), [#6353](https://github.com/amd/gaia/pull/6353), [#6335](https://github.com/amd/gaia/pull/6335), [#6345](https://github.com/amd/gaia/pull/6345), [#6378](https://github.com/amd/gaia/pull/6378), [#6363](https://github.com/amd/gaia/pull/6363), [#6180](https://github.com/amd/gaia/pull/6180))
- **Releases can't publish with a desktop installer missing or agent version files out of step**, and the hub rejects artifacts named like its own docs. (PRs [#6356](https://github.com/amd/gaia/pull/6356), [#6355](https://github.com/amd/gaia/pull/6355), [#6302](https://github.com/amd/gaia/pull/6302), [#6183](https://github.com/amd/gaia/pull/6183))
- **Docs** — fixed broken links and stale names (`gaia tui`, deleted agents, `--bypass-permissions`), synced the CLI reference with the parser, added Git and Memory connector pages, and corrected the guides, quickstart extras, skills, eval, VLM and `/query` pages. (PRs [#6066](https://github.com/amd/gaia/pull/6066), [#6129](https://github.com/amd/gaia/pull/6129), [#6147](https://github.com/amd/gaia/pull/6147), [#6146](https://github.com/amd/gaia/pull/6146), [#6145](https://github.com/amd/gaia/pull/6145), [#6133](https://github.com/amd/gaia/pull/6133), [#6134](https://github.com/amd/gaia/pull/6134), [#6135](https://github.com/amd/gaia/pull/6135), [#6137](https://github.com/amd/gaia/pull/6137), [#6113](https://github.com/amd/gaia/pull/6113), [#6310](https://github.com/amd/gaia/pull/6310), [#6324](https://github.com/amd/gaia/pull/6324), [#6319](https://github.com/amd/gaia/pull/6319), [#6332](https://github.com/amd/gaia/pull/6332), [#6308](https://github.com/amd/gaia/pull/6308), [#6237](https://github.com/amd/gaia/pull/6237), [#6246](https://github.com/amd/gaia/pull/6246), [#6247](https://github.com/amd/gaia/pull/6247), [#6294](https://github.com/amd/gaia/pull/6294), [#6238](https://github.com/amd/gaia/pull/6238), [#6239](https://github.com/amd/gaia/pull/6239), [#6225](https://github.com/amd/gaia/pull/6225), [#6220](https://github.com/amd/gaia/pull/6220), [#6218](https://github.com/amd/gaia/pull/6218), [#6205](https://github.com/amd/gaia/pull/6205), [#6175](https://github.com/amd/gaia/pull/6175), [#6201](https://github.com/amd/gaia/pull/6201), [#6227](https://github.com/amd/gaia/pull/6227))

## Known Issues

- **A relayed GAIA turn can lose its final answer after you approve a prompt**, about one time in ten. It says the step didn't run; send the message again. Tracked in [#6019](https://github.com/amd/gaia/issues/6019).
