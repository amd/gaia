Ask your PC to find that contract you downloaded last month. Drop in a spreadsheet and get an instant analysis. Search across thousands of files in seconds. GAIA Agent UI is one chat window for the GAIA agent. It runs on your PC by default, and uses a cloud provider (Fireworks AI or the AMD LLM Gateway) only when you pick one of its models.

## What you need

- A Windows, Linux or macOS PC. Setup checks what it can run and suggests a model that fits; any PC can use a cloud model instead.
- Room for a model if you run locally: about 6 GB for the default, about 30 GB for the larger one. Setup shows the exact size before anything downloads.
- No account and no API key to run locally.

## Local first, cloud when you choose

GAIA answers on your PC by default: your messages, files and documents stay on it, and nothing needs an account. You can connect Fireworks AI or the AMD LLM Gateway and pick one of their models instead. The model chip then names the provider, and each message is sent to it. See [Models, control and privacy](/guides/agent-ui/control).
