`gaia-tui` opens the flagship GAIA agent: conversation, documents, files, data,
web research, memory, and skills. The Python `gaia` CLI is a separate program.

## Install and launch

Get the terminal installer for your platform from
[GAIA downloads](https://amd-gaia.ai/#install) or the
[release assets](https://github.com/amd/gaia/releases/latest). Open a new terminal
so it receives the updated PATH, then run:

```bash
gaia-tui
```

The native terminal installer includes `gaia-tui` and the flagship `gaia-agent`.
Building the Go client alone does not install the agent or model backend.
See [building from source](/reference/tui#build-and-test).

The launch shows a splash, checks readiness, and opens chat. A missing agent
binary points back to the installer. A missing local backend or model offers
setup where supported. The focused row names the failure and its remedy.

| Readiness key | Action |
| --- | --- |
| `f` | Run the focused row's fix, when offered |
| `p` | Open the provider picker for flagship setup |
| `r` | Re-check |
| `d` | Show details |
| Arrow keys or `j` / `k` | Select a row |
| `Enter` | Continue when offered; failed rows block launch |
| `Esc`, `Ctrl+C` | Quit |

`[ok]` means checked, `[!]` failed, `[?]` unverified, `[ ]` waiting, and `[..]`
checking. An unverified result is not a successful check; consequential uncertainty,
such as insufficient model context, can require an explicit Enter to proceed.

## Try your first conversation

Once chat opens, send a short request such as **“Explain what you can help me do.”**
Then try a file task:

1. Drag a text file from your home directory into the composer to insert its path.
2. Add **“Summarize this file in three bullets”** and press Enter.
3. Read the tool activity and answer. Follow up with **“Which part supports the second bullet?”**

GAIA reads files through tools; inserting a path does not upload or attach the
entire file by itself. File access is limited to allowed directories. Cloud
inference can send retrieved file content to the chosen provider. See
[flagship capabilities and file scope](/guides/gaia#permissions-and-file-scope).

## Choose inference

Local chat uses Lemonade. Press `p` during setup or enter `/provider` in chat to
choose Local, Fireworks AI, or AMD LLM Gateway. Provider changes affect other clients
of that Lemonade server. Cloud chat sends conversation history to the selected
provider; web tools and connectors make their own network requests.

Use [AI providers](/guides/ai-providers) for credentials, model selection,
embedding requirements, and recovery. `/model` lists or switches models on the
flagship subprocess; unsupported transports report the restriction.

## Chat controls

| Key | Action |
| --- | --- |
| `Enter` | Send; queue the message if a turn is running |
| `Alt+Enter`, `Ctrl+J` | Insert a newline |
| `Esc` while idle | Clear the composer |
| `Esc` while streaming | Request cancellation; a second press forces a stop |
| `Ctrl+C` while idle | Quit |
| `Ctrl+C` while streaming | Request cancellation; a second press forces a stop |
| `↑` / `↓`, `PgUp` / `PgDn` | Scroll the conversation |
| `Home` / `End` with an empty composer | Jump to the top / bottom |
| `Ctrl+V` | Paste text or save a clipboard image and insert its path |
| `Ctrl+Y` | Copy the answer |
| `Ctrl+B` | Copy the last code block |
| `Ctrl+T` | Toggle terminal selection mode |

The first stop request returns queued messages to the composer. A second stop
abandons any follow-ups still queued and reports what was dropped. A queued
follow-up that runs longer than three minutes shows a stop/recovery hint; the
hint itself does not cancel it.

A forced subprocess stop restarts the agent and loses in-memory skills and grants.
It is different from cancelling a turn cooperatively. Persistent memory is separate
from the current conversation; see [state and cancellation](/reference/tui#state-and-cancellation).

Drag a file or folder into the terminal to insert its path. The mouse wheel scrolls
chat. Links open in a browser; double-clicking a message copies it. Hold the terminal's
selection modifier (often Shift; Option in iTerm2) or use `Ctrl+T` for native selection.
In selection mode, GAIA does not receive mouse clicks or wheel events.

## Commands and approval

Type `/` in an empty composer to open the searchable palette. Use arrows and Enter,
or select a row with the mouse. `/help` shows the full shortcuts.

| Command | Action |
| --- | --- |
| `/help` | Show help |
| `/clear` | Clear the visible transcript; see session behavior below |
| `/memory` | Inspect agent memory |
| `/setup` | Run flagship setup |
| `/model` | List models; `/model <id>` requests a switch |
| `/provider` | Configure local or cloud inference |
| `/bypass` | Show the warning before enabling permission bypass |
| `/bypass off` | Restore tool confirmation |

Commands that depend on a subprocess capability are unavailable on daemon-backed
sessions. Permission bypass is off by default. A daemon-backed session rejects
`--bypass-permissions`; it does not silently disable its approval policy.

When a question appears, select an option with arrows, Tab, or its number and press
Enter. Esc cancels the turn. Read the requested action before approving a tool.

## Clear or start over

`/clear` clears the screen. With the flagship subprocess, the agent still retains
its recent conversation, loaded skills, and temporary grants. To start a new
subprocess conversation, quit while idle and relaunch `gaia-tui`. Persistent
memory remains available after relaunch.

On a daemon-backed session, `/clear` also drops the client’s conversation context
and session ID, so the next message starts a new session. Neither path deletes
persistent memory. See [state and cancellation](/reference/tui#state-and-cancellation).

## Other agents and scripts

```bash
gaia hub list
gaia hub install email --trust
gaia-tui run email
gaia-tui run email --query "How many unread messages do I have?" --timeout 90s
```

Only trust packages whose publisher and requested access you accept. Installation
and removal belong to the Python CLI, not the terminal client.

For `run --query` and `chat --agent --query`, the answer goes to stdout and progress
to stderr. Exit `0` means answered without an unrecovered failure, `1` means failure,
and `3` means an approval gate blocked the action. The default turn timeout is 15m.
Interactive `chat --subprocess --query` instead sends an initial message and stays open.

`gaia-tui status` inspects the daemon and installed agents. It does not start the
daemon and exits nonzero if it cannot reach it; that does not by itself mean a
standalone flagship subprocess cannot run.

## Diagnose a problem

```bash
gaia-tui --dev --trace=run.jsonl
```

`--dev` shows detailed activity; `--trace` records received agent events. Review a
trace before sharing: it can contain document contents, tool arguments, and email.
For light or dark terminals, set `GAIA_TUI_THEME=light` or `dark` (default `auto`).

See [TUI architecture and troubleshooting](/reference/tui), the
[CLI reference](/reference/cli#terminal-ui-gaia-tui), and
[TUI control MCP](/guides/mcp/tui) for programmatic testing.
