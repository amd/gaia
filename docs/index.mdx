GAIA is AMD's open-source agent framework. The flagship agent combines conversation,
document retrieval, file and shell tools, data analysis, memory, and skills. The
terminal UI provides interactive chat, tool approval, cancellation, and diagnostics.

Local inference runs through Lemonade. Optional cloud providers send conversation
history to the selected service; web tools and connectors also contact external
services. See [AI providers](/guides/ai-providers).
