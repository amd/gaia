## Quick Start

<Note>
The server exposes one model, `gaia` — the flagship agent. Capability that used to mean picking a different agent is now a skill it loads on demand. Register more in `AGENT_MODELS` ([`src/gaia/api/agent_registry.py`](https://github.com/amd/gaia/blob/main/src/gaia/api/agent_registry.py)); see [Adding New Agents](/reference/api-spec#adding-new-agents).
</Note>

<Steps>
  <Step title="Start Lemonade Server">
    ```bash
    lemonade-server serve --ctx-size 32768
    ```
  </Step>

  <Step title="Start GAIA API Server">
    ```bash
    gaia api start
    ```
  </Step>

  <Step title="Test the Server">
    <CodeGroup>
    ```bash Health Check
    curl http://localhost:8080/health
    ```

    ```bash List Models
    curl http://localhost:8080/v1/models
    ```

    ```bash Make Request
    curl -X POST http://localhost:8080/v1/chat/completions \
      -H "Content-Type: application/json" \
      -d '{
        "model": "your-agent-id",
        "messages": [{"role": "user", "content": "Write a hello world function"}]
      }'
    ```
    </CodeGroup>

    The health response includes API, Lemonade LLM, and RAG component status.
    A running API returns HTTP 200 with top-level status `degraded` when
    Lemonade is unavailable or has no LLM loaded.
  </Step>
</Steps>

## Server Management

### Start Server

<Tabs>
  <Tab title="Basic">
    Start in foreground:

    ```bash
    gaia api start
    ```
  </Tab>

  <Tab title="Background">
    `gaia api start` has **no `--background` flag** — detach via your shell
    (only `gaia mcp start` supports `--background` natively):

    ```bash
    # Unix: use nohup + &
    nohup gaia api start > api.log 2>&1 &
    ```

    ```powershell
    # Windows: start a detached PowerShell process
    Start-Process -NoNewWindow gaia -ArgumentList "api","start"
    ```
  </Tab>

  <Tab title="Debug">
    Start with debug logging:

    ```bash
    gaia api start --debug
    ```
  </Tab>

  <Tab title="Custom">
    Custom host/port:

    ```bash
    gaia api start --host 0.0.0.0 --port 8888
    ```
  </Tab>
</Tabs>

### Check Status

```bash
gaia api status
```

### Stop Server

```bash
gaia api stop
```

## Usage Examples

### Python (OpenAI Client)

<CodeGroup>
```python Basic Usage
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="your-agent-id",
    messages=[{"role": "user", "content": "Create a REST API with Express and SQLite"}]
)

print(response.choices[0].message.content)
```

```python Second Request
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="not-needed"
)

response = client.chat.completions.create(
    model="your-agent-id",
    messages=[{"role": "user", "content": "Create a Django REST API with authentication"}]
)

print(response.choices[0].message.content)
```

```python Streaming
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8080/v1",
    api_key="not-needed"
)

stream = client.chat.completions.create(
    model="your-agent-id",
    messages=[{"role": "user", "content": "Write a calculator class"}],
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
```
</CodeGroup>

### JavaScript/Node.js

<CodeGroup>
```javascript Axios
const axios = require('axios');

async function chat(message) {
    const response = await axios.post(
        'http://localhost:8080/v1/chat/completions',
        {
            model: 'your-agent-id',
            messages: [{ role: 'user', content: message }]
        }
    );
    return response.data.choices[0].message.content;
}

chat('Build me a todo app using nextjs').then(console.log);

chat('Write a Python function to calculate factorial').then(console.log);
```

```javascript Fetch
async function chat(message) {
    const response = await fetch('http://localhost:8080/v1/chat/completions', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            model: 'your-agent-id',
            messages: [{ role: 'user', content: message }]
        })
    });
    const data = await response.json();
    return data.choices[0].message.content;
}
```
</CodeGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Server Won't Start" icon="circle-xmark">
    **Check if port is in use:**

    <Tabs>
      <Tab title="Mac/Linux">
        ```bash
        lsof -i :8080
        ```
      </Tab>
      <Tab title="Windows">
        ```bash
        netstat -ano | findstr :8080
        ```
      </Tab>
    </Tabs>

    **Try different port:**
    ```bash
    gaia api start --port 8888
    ```
  </Accordion>

  <Accordion title="Connection Refused" icon="link-slash">
    **Verify server is running:**
    ```bash
    gaia api status
    ```

    **Check health endpoint:**
    ```bash
    curl http://localhost:8080/health
    ```

    Check `components.llm` when the top-level status is `degraded`.
  </Accordion>

  <Accordion title="Agent Errors" icon="triangle-exclamation">
    **Check Lemonade is running:**
    ```bash
    curl http://localhost:13305/health
    ```

    **Verify context size:**
    ```bash
    lemonade-server serve --ctx-size 32768
    ```

    **Enable debug mode:**
    ```bash
    gaia api start --debug
    ```
  </Accordion>
</AccordionGroup>

### Common Issues

| Issue | Solution |
|-------|----------|
| "Model not found" | Confirm the model id is registered in `AGENT_MODELS` — `GET /v1/models` lists what's actually available |
| "Agent processing failed" | Ensure Lemonade is running with `--ctx-size 32768` |
| "Port already in use" | Stop existing server or use `--port` flag |
| Streaming not working | Ensure `"stream": true` in request |
