## Overview

FileChangeHandler provides a reusable file system watcher for GAIA agents. It monitors directories for file changes (create, modify, delete) and triggers callbacks, enabling agents to automatically process new files.

**Key Features:**
- File event detection (create, modify, delete)
- Callback-based architecture
- File extension filtering
- Custom filter function and directory-event skipping
- Reports a file once it has finished being written, so a burst of events is one callback
- Integration with watchdog library

---

## Requirements

### Functional Requirements

1. **File Event Handling**
   - Detect file creation
   - Detect file modification
   - Detect file deletion
   - Optional: Detect file moves

2. **Filtering**
   - File extension filters (`None` = `DEFAULT_EXTENSIONS`, `[]` = every file)
   - A custom `filter_func(path)` that takes precedence over extensions
   - Directory events skipped by default (`ignore_directories=True`)

3. **Settling**
   - Report a created or modified file once it has had no events, and no size or
     mtime change, for the configured window
   - Coalesce rapid successive changes into one callback
   - Run callbacks on a dispatch thread, off the observer thread

4. **Callback System**
   - `on_created(path)`, `on_modified(path)` and `on_deleted(path)` callbacks
   - `on_moved(src_path, dest_path)` callback
   - Callbacks receive the path as a `str`, not a watchdog event
   - Telemetry counters (`telemetry`, `reset_telemetry()`)

5. **Integration with watchdog**
   - Extends `FileSystemEventHandler`
   - Works with `Observer`
   - Thread-safe

### Non-Functional Requirements

1. **Performance**
   - Low overhead monitoring
   - Efficient event filtering
   - Non-blocking callbacks

2. **Reliability**
   - Handle edge cases (permission errors, symlinks)
   - Graceful degradation
   - Proper cleanup

3. **Usability**
   - Simple API
   - Good defaults
   - Clear error messages

### Public Interface

```python
class FileChangeHandler(FileSystemEventHandler):
    """
    Generic file system watcher with callback support.

    Callbacks receive the file path as a str. A created or modified file is
    reported once it settles, on a dispatch thread rather than the observer's.

    Usage:
        def process_new_file(path: str):
            print(f"New file: {path}")

        handler = FileChangeHandler(
            on_created=process_new_file,
            extensions=[".pdf", ".png"],
        )

        from watchdog.observers import Observer
        observer = Observer()
        observer.schedule(handler, "/path/to/watch", recursive=False)
        observer.start()
    """

    DEFAULT_EXTENSIONS: List[str] = [".pdf", ".txt", ".md", ...]  # see source

    def __init__(
        self,
        on_created: Optional[Callable[[str], None]] = None,
        on_modified: Optional[Callable[[str], None]] = None,
        on_deleted: Optional[Callable[[str], None]] = None,
        on_moved: Optional[Callable[[str, str], None]] = None,  # (src, dest)
        extensions: Optional[List[str]] = None,  # None = DEFAULT_EXTENSIONS, [] = all files
        filter_func: Optional[Callable[[str], bool]] = None,  # takes precedence over extensions
        debounce_seconds: float = 2.0,  # quiet window before a file is reported
        ignore_directories: bool = True,
    ): ...

    # Event handlers called by watchdog
    def on_created(self, event: FileSystemEvent) -> None: ...
    def on_modified(self, event: FileSystemEvent) -> None: ...
    def on_deleted(self, event: FileSystemEvent) -> None: ...
    def on_moved(self, event: FileSystemEvent) -> None: ...

    def _should_process(self, file_path: str) -> bool: ...

    # Lifecycle and statistics
    def wait_idle(self, timeout: Optional[float] = None) -> bool: ...
    def close(self) -> None: ...
    def reopen(self) -> None: ...
    @property
    def telemetry(self) -> Dict[str, Any]: ...
    def reset_telemetry(self) -> None: ...

    # _schedule_settle / _schedule_now / the dispatch thread: see
    # "Settling Implementation" below.
```

`FileWatcher` (a handler plus a watchdog `Observer`, with `start()`, `stop()`,
`is_running`, `directory` and `telemetry`) and `FileWatcherMixin`
(`watch_directory()`, `stop_all_watchers()`, `watchers`, `watching_directories`,
`watcher_telemetry`) live in the same module. See the
[FileWatcher guide](/sdk/utils/file-watcher) for their full API.

## Testing Requirements

### Unit Tests

**Files:** `tests/unit/test_file_watcher.py`, `tests/unit/test_file_watcher_settle.py`

```python
import time
from pathlib import Path

from gaia import FileChangeHandler
from watchdog.observers import Observer
from watchdog.events import FileCreatedEvent

def test_a_burst_of_events_is_reported_once_after_it_settles(tmp_path):
    """Rapid events on one file give one callback, after the quiet window."""
    seen = []
    target = tmp_path / "test.txt"
    target.write_text("done")
    handler = FileChangeHandler(on_created=seen.append, debounce_seconds=0.5)

    event = FileCreatedEvent(str(target))
    handler.on_created(event)
    handler.on_created(event)  # coalesced with the first
    handler.on_created(event)  # coalesced with the first
    assert seen == []  # not reported until it has been quiet for 0.5 s

    assert handler.wait_idle(5)
    assert seen == [str(target)]
    handler.close()

def test_real_file_watching(tmp_path):
    """Test with real file system changes."""
    processed_files = []

    def on_create(path):
        processed_files.append(Path(path).name)

    handler = FileChangeHandler(
        on_created=on_create,
        extensions=[".txt"],
        debounce_seconds=0.2,
    )

    observer = Observer()
    observer.schedule(handler, str(tmp_path), recursive=False)
    observer.start()

    try:
        # Create a file
        test_file = tmp_path / "test.txt"
        test_file.write_text("test content")

        # Let the event arrive, then wait for the file to settle and the callback to run
        time.sleep(0.5)
        assert handler.wait_idle(5)

        # Verify callback was triggered
        assert "test.txt" in processed_files

    finally:
        observer.stop()
        observer.join(timeout=5)
        handler.close()
```

## Usage Examples

### Example 1: Form Intake Agent (Auto-Process Forms)

```python
from gaia import Agent, FileChangeHandler
from gaia.llm import VLMClient
from watchdog.observers import Observer
from pathlib import Path

class FormIntakeAgent(Agent):
    """Process scanned forms automatically."""

    def __init__(self, watch_dir: str = "./intake_forms", **kwargs):
        super().__init__(**kwargs)
        self.watch_dir = Path(watch_dir)
        self.watch_dir.mkdir(exist_ok=True)
        self.vlm = VLMClient()
        self._observer = None
        self._start_watching()

    def _start_watching(self):
        """Start watching for new intake forms."""
        def process_new_form(path):
            print(f"New form detected: {path}")
            # Extract data from form
            result = self._extract_form_data(path)
            print(f"Extracted: {result}")

        handler = FileChangeHandler(
            on_created=process_new_form,
            extensions=[".pdf", ".png", ".jpg"],
            debounce_seconds=2.0
        )

        self._observer = Observer()
        self._observer.schedule(handler, str(self.watch_dir), recursive=False)
        self._observer.start()
        print(f"Watching: {self.watch_dir}")

    def _extract_form_data(self, image_path: str) -> dict:
        """Extract data from intake form."""
        path = Path(image_path)
        image_bytes = path.read_bytes()
        extracted = self.vlm.extract_from_image(image_bytes, prompt="Extract form fields")
        return {"file": str(path), "data": extracted}

    def __del__(self):
        """Stop watching on cleanup."""
        if self._observer:
            self._observer.stop()
            self._observer.join(timeout=5)
```

### Example 2: Document Indexing Agent

```python
from pathlib import Path

from gaia import Agent, FileChangeHandler
from gaia.rag.sdk import RAGSDK, RAGConfig
from watchdog.observers import Observer

class AutoIndexAgent(Agent):
    """Automatically index new documents."""

    def __init__(self, docs_dir: str = "./docs", **kwargs):
        super().__init__(**kwargs)
        self.rag = RAGSDK(RAGConfig())
        self._setup_watching(docs_dir)

    def _setup_watching(self, docs_dir: str):
        """Watch directory for new documents."""
        def index_new_doc(path):
            print(f"Indexing: {path}")
            self.rag.index_document(path)
            print(f"✅ Indexed: {Path(path).name}")

        handler = FileChangeHandler(
            on_created=index_new_doc,
            extensions=[".pdf", ".txt", ".md", ".docx"]
        )

        observer = Observer()
        observer.schedule(handler, docs_dir, recursive=True)
        observer.start()
        print(f"Auto-indexing enabled for: {docs_dir}")
```

## Implementation Details

### Extraction from ChatAgent (Completed)

`FileChangeHandler` was originally embedded in `hub/agents/gaia/python/gaia_agent/chat_agent.py` as a tightly-coupled inner class. It has been extracted to `src/gaia/utils/file_watcher.py` as a generic, callback-based implementation. ChatAgent now imports it from there:

```python
from gaia.utils.file_watcher import FileChangeHandler
```

The callback-based design decouples the handler from any specific agent: each callback receives the file path as a `str`, and the handler queues the path to settle before calling it.

### Settling Implementation

A created or modified path is held in `_pending` with a due time
`debounce_seconds` after its latest event and its `(size, mtime_ns)` at that
event. A dispatch thread, never the observer's, wakes at the earliest due time
and stats each due path outside the lock:

- unchanged since its last event: the callback runs;
- changed (still being written): it waits another full window;
- gone: it is dropped, since its delete event reports it.

Deletes and moves are dispatched in arrival order and cancel a pending report
for their path. A callback that raises is logged with its traceback. An
`on_created` or `on_modified` callback that raises `PermissionError` (the writer
still holds the file exclusively) is retried after 1, 2 and 4 windows; an
`on_moved` callback that raises it has its destination retried the same way,
as a modification. After the last retry the file is given up on with one
error, logged with its traceback, that tells the user to close the program
using the file and save it again. A callback must let `PermissionError`
propagate for this to work; catching it disables the retry. A file that
never pauses (a log written constantly) is not reported until it does.
`wait_idle()` blocks until everything queued has been dispatched, and
`close()` stops the dispatcher, dropping (and logging) what it had not yet
reported.

### Extension Filtering

```python
def _should_process(self, file_path: str) -> bool:
    """Check if file should be processed based on filters."""
    # Custom filter takes precedence
    if self._filter_func is not None:
        return self._filter_func(file_path)

    # Empty extensions list means watch all files
    if not self._extensions:
        return True

    file_lower = file_path.lower()
    return any(file_lower.endswith(ext) for ext in self._extensions)
```

Extensions are normalized to lowercase with a leading dot. There are no ignore patterns; use `filter_func` to exclude files.
