## Overview

Test Utilities provide fixtures, mocks, and helper functions for testing GAIA agents without requiring real LLMs, databases, or network resources. This enables fast, reliable unit testing for both GAIA framework and third-party agents.

**Key Features:**
- Mock LLM provider with configurable responses
- Mock VLM client for image processing
- Temporary database fixtures with auto-cleanup
- Agent test factory with mocked dependencies
- Assertion helpers for common test patterns

---

## Requirements

### Functional Requirements

1. **Mock LLM Provider**
   - Simulate LLM responses without API calls
   - Configurable response sequences
   - Track call history for assertions

2. **Mock VLM Client**
   - Simulate image text extraction
   - Configurable extracted text
   - Track calls for testing

3. **Temporary Database**
   - Temporary on-disk SQLite file for testing
   - Automatic cleanup
   - Isolation between tests

4. **Agent Test Factory**
   - Create agents with mocked dependencies
   - Simplified agent instantiation
   - Pre-configured for testing

5. **Assertion Helpers**
   - Verify tool calls
   - Check agent state
   - Validate responses

### Non-Functional Requirements

1. **Performance**
   - Fast test execution (no real API calls)
   - Minimal setup overhead

2. **Ease of Use**
   - Simple, intuitive API
   - Good defaults
   - Clear error messages

3. **Isolation**
   - Tests don't interfere with each other
   - Clean state between tests

### Public Interface

#### mocks.py

```python
class MockLLMProvider:
    def __init__(
        self,
        responses: Optional[List[str]] = None,    # returned in sequence, cycling
        tool_responses: Optional[Dict[str, Any]] = None,  # tool name -> mock result
        default_response: str = "Mock LLM response",  # used when responses is empty
    ): ...

    def generate(self, prompt, system_prompt=None, temperature=0.7, max_tokens=None, **kwargs) -> str: ...
    def chat(self, messages, **kwargs) -> str: ...   # records the last user message as the prompt
    def stream(self, prompt, **kwargs) -> Iterator[str]: ...  # yields the whole reply as one chunk
    def complete(self, prompt, **kwargs) -> str: ...  # alias for generate()
    def get_tool_response(self, tool_name) -> Any: ...  # tool_responses entry, else {"status": "success"}

    call_history: List[Dict[str, Any]]
    was_called: bool       # property
    call_count: int        # property
    last_prompt: Optional[str]  # property

    def reset(self) -> None: ...                       # clear history and response index
    def set_responses(self, responses: List[str]) -> None: ...

class MockVLMClient:
    def __init__(
        self,
        extracted_text: str = "Mock extracted text",
        extraction_results: Optional[List[str]] = None,  # returned in sequence, cycling
        is_available: bool = True,                       # check_availability() result
    ): ...

    def check_availability(self) -> bool: ...
    def extract_from_image(self, image_bytes, prompt=None, **kwargs) -> str: ...
    def extract_from_file(self, file_path, prompt=None, **kwargs) -> str: ...
    def describe_image(self, image_bytes, prompt=None, **kwargs) -> str: ...

    call_history: List[Dict[str, Any]]
    was_called: bool       # property
    call_count: int        # property
    last_prompt: Optional[str]  # property

    def reset(self) -> None: ...
    def set_extracted_text(self, text: str) -> None: ...

class MockToolExecutor:
    def __init__(
        self,
        results: Optional[Dict[str, Any]] = None,         # tool name -> result
        default_result: Optional[Dict[str, Any]] = None,  # default {"status": "success"}
    ): ...

    def execute(self, tool_name: str, args: Dict[str, Any]) -> Any: ...
    def was_tool_called(self, tool_name: str) -> bool: ...
    def get_tool_calls(self, tool_name: str) -> List[Dict[str, Any]]: ...
    def get_tool_args(self, tool_name: str, call_index: int = 0) -> Optional[Dict]: ...

    call_history: List[Dict[str, Any]]
    tool_names_called: List[str]   # property

    def reset(self) -> None: ...
```

#### fixtures.py

```python
def create_test_agent(
    agent_class: Type[AgentT],
    mock_responses: Optional[List[str]] = None,
    mock_vlm_text: Optional[str] = None,   # attach a MockVLMClient returning this text
    inject_mocks: bool = True,             # False: build the agent without mocks
    **agent_kwargs,
) -> AgentT:
    """Create an agent with skip_lemonade=True and silent_mode=True (both overridable).

    With inject_mocks=True the MockLLMProvider is stored on agent._mock_llm (and
    on agent.chat when the agent has one); the MockVLMClient on agent._mock_vlm
    (and agent.vlm when the agent has one).
    """
```

`create_test_agent` replaces `agent.chat` with a `MockLLMProvider`, which has no
`send_messages()` — the method the agent loop calls — so it builds agents for
construction and tool tests but cannot drive `process_query()` end to end. To test
the loop, patch `gaia.agents.base.agent.AgentSDK` as shown in the
[SDK testing guide](/sdk/testing).

```python
class AgentTestContext:
    """Context manager: temp directory, mock providers, agent, and cleanup.

    Attributes: agent, mock_llm, mock_vlm, temp_dir
    Methods: create_file(...), create_directory(name),
             set_llm_responses(responses), set_vlm_text(text)
    """
    def __init__(self, agent_class, mock_responses=None, mock_vlm_text=None, **agent_kwargs): ...

@contextmanager
def temp_directory():
    """Yield a Path to a temporary directory, deleted on exit."""

@contextmanager
def temp_file(content: str = "", suffix: str = ".txt", prefix: str = "test_"):
    """Yield a Path to a temporary file with the given content, deleted on exit."""

@contextmanager
def temp_db(schema: Optional[str] = None):
    """Yield the path to a temporary SQLite database (defined in src/gaia/database/testing.py)."""
```

#### assertions.py

| Function | Checks |
|----------|--------|
| `assert_llm_called(mock_llm, times=None, min_times=None, max_times=None)` | The mock LLM was called (exactly `times`, or within the bounds) |
| `assert_llm_prompt_contains(mock_llm, text, call_index=-1)` | A recorded LLM prompt contains `text` |
| `assert_vlm_called(mock_vlm, times=None)` | The mock VLM was called |
| `assert_tool_called(executor, tool_name, times=None)` | A `MockToolExecutor` ran the tool (exactly `times` if given) |
| `assert_tool_args(executor, tool_name, expected_args, call_index=0)` | A tool call received the expected arguments |
| `assert_result_has_keys(result, keys)` | A result dict has every key in `keys` |
| `assert_result_value(result, key, expected)` | `result[key] == expected` |
| `assert_agent_completed(result, has_answer=True)` | A `process_query()` result is not an error and has an `answer`, `response` or `result` key |
| `assert_no_errors(result)` | A result dict carries no error indicators |

`process_query()` returns its answer under `"result"`, not `"answer"`.

## Testing Requirements

### Unit Tests

**File:** `tests/unit/test_testing_utilities.py`

```python
from pathlib import Path

import pytest
from gaia.testing import (
    MockLLMProvider,
    MockVLMClient,
    create_test_agent,
    temp_db,
    temp_directory,
)
from gaia import Agent

def test_mock_llm_can_be_imported():
    """Verify MockLLMProvider can be imported."""
    from gaia.testing import MockLLMProvider
    assert MockLLMProvider is not None

def test_mock_llm_returns_responses():
    """Test MockLLMProvider returns configured responses."""
    mock = MockLLMProvider(responses=["Response 1", "Response 2"])

    assert mock.generate("test") == "Response 1"
    assert mock.generate("test") == "Response 2"
    assert mock.generate("test") == "Response 1"  # Cycles

def test_mock_llm_tracks_calls():
    """Test MockLLMProvider tracks call history."""
    mock = MockLLMProvider()

    mock.generate("prompt 1", temperature=0.7)
    mock.generate("prompt 2", max_tokens=100)

    assert len(mock.call_history) == 2
    assert mock.call_history[0]["prompt"] == "prompt 1"
    assert mock.call_history[1]["max_tokens"] == 100

def test_mock_vlm_can_be_imported():
    """Verify MockVLMClient can be imported."""
    from gaia.testing import MockVLMClient
    assert MockVLMClient is not None

def test_mock_vlm_returns_text():
    """Test MockVLMClient returns configured text."""
    mock = MockVLMClient(extracted_text="Extracted data")

    result = mock.extract_from_image(b"fake image bytes", prompt="Extract text")

    assert result == "Extracted data"
    assert mock.was_called

def test_temp_db_creates_and_cleans_up():
    """Test temp_db fixture."""
    with temp_db() as db_path:
        assert Path(db_path).parent.exists()

    # After context, the temp directory is deleted
    assert not Path(db_path).exists()

def test_temp_db_with_schema():
    """Test temp_db with a schema."""
    import sqlite3

    with temp_db("CREATE TABLE users (id INTEGER PRIMARY KEY);") as db_path:
        conn = sqlite3.connect(db_path)
        cursor = conn.execute("SELECT name FROM sqlite_master WHERE type='table'")
        tables = [row[0] for row in cursor.fetchall()]

        assert "users" in tables
        conn.close()

def test_temp_directory_creates_and_cleans_up():
    """Test temp_directory fixture."""
    created_path = None

    with temp_directory() as tmp_dir:
        created_path = tmp_dir

        # Directory should exist
        assert tmp_dir.exists()
        assert tmp_dir.is_dir()

        # Should be usable
        test_file = tmp_dir / "test.txt"
        test_file.write_text("content")
        assert test_file.exists()

    # After context, directory should be deleted
    assert not created_path.exists()

def test_create_test_agent():
    """Test create_test_agent helper."""
    class TestAgent(Agent):
        def _get_system_prompt(self): return "Test"
        def _register_tools(self): pass

    agent = create_test_agent(
        TestAgent,
        mock_responses=["Response from mock"]
    )

    assert agent is not None
    assert isinstance(agent, TestAgent)
    # Should have mocked LLM (verify based on implementation)
```

## Usage Examples

### Example 1: Testing Agent with Mock LLM

```python
import pytest
from gaia.testing import create_test_agent, MockLLMProvider
from my_agent import MyAgent

def test_agent_processes_query():
    """Test agent with mocked LLM."""
    agent = create_test_agent(
        MyAgent,
        mock_responses=[
            '{"tool": "search", "args": {"query": "test"}}',
            "Found results from search."
        ]
    )

    # The mock stands in for the real LLM client
    assert agent._mock_llm is not None
    assert agent.chat is agent._mock_llm
```

<Note>
`MockLLMProvider` has no `send_messages()`, which the agent loop calls, so this flow does not drive the real loop. Use it to construct agents and test tools; to test `process_query()` patch `gaia.agents.base.agent.AgentSDK` (see [SDK testing](/sdk/testing)).
</Note>

### Example 2: Testing Database Agent

```python
import pytest
from gaia.testing import temp_db
from gaia import Agent, DatabaseMixin

def test_customer_agent_creates_record(tmp_path):
    """Test agent can create database records."""
    # Create schema
    schema = tmp_path / "schema.sql"
    schema.write_text("""
        CREATE TABLE customers (
            id INTEGER PRIMARY KEY,
            name TEXT NOT NULL
        );
    """)

    # Test with temporary database
    with temp_db(schema.read_text()) as db_path:
        agent = CustomerAgent(skip_lemonade=True)
        agent.init_db(db_path)

        # Tools are regular Python functions — call them directly
        from gaia.agents.base.tools import _TOOL_REGISTRY
        result = _TOOL_REGISTRY["create_customer"]["function"](
            name="Test Customer"
        )

        assert result["status"] == "created"

        # Verify in database
        customers = agent.query("SELECT * FROM customers")
        assert len(customers) == 1
        assert customers[0]["name"] == "Test Customer"

    # Database automatically cleaned up
```

### Example 3: Testing VLM Integration

```python
import pytest
from gaia.testing import MockVLMClient
from my_agent import FormProcessingAgent

def test_form_extraction():
    """Test form extraction with mock VLM."""
    agent = FormProcessingAgent()

    # Mock VLM response
    agent.vlm = MockVLMClient(
        extracted_text='{"first_name": "John", "last_name": "Doe"}'
    )

    # Test extraction — invoke the registered tool function directly
    from gaia.agents.base.tools import _TOOL_REGISTRY
    result = _TOOL_REGISTRY["extract_form"]["function"](
        image_path="fake.png"
    )

    # Verify VLM was called
    assert agent.vlm.was_called
    assert len(agent.vlm.call_history) == 1

    # Verify result
    assert "first_name" in result
    assert result["first_name"] == "John"
```

### Example 4: Testing File Watching

```python
import pytest
from gaia.testing import temp_directory
import time

def test_agent_processes_new_files():
    """Test agent processes files dropped in watched directory."""
    with temp_directory() as tmp_dir:
        agent = FileWatchAgent(watch_dir=str(tmp_dir))

        # Drop a file
        test_file = tmp_dir / "test.pdf"
        test_file.write_text("content")

        # Wait for processing
        time.sleep(1)

        # Verify agent processed it
        assert agent.processed_count == 1

    # Directory cleaned up automatically
```

## pytest Fixtures

### Fixture Exports

GAIA's own `conftest.py` does not define these; a test suite can add them like this:

```python
import pytest
from gaia.testing import temp_db, temp_directory, MockLLMProvider

@pytest.fixture
def mock_llm():
    """Provide MockLLMProvider fixture."""
    return MockLLMProvider()

@pytest.fixture
def db_path():
    """Provide temporary database fixture."""
    with temp_db() as path:
        yield path

@pytest.fixture
def tmp_dir():
    """Provide temporary directory fixture."""
    with temp_directory() as tmp_path:
        yield tmp_path
```

**Third-party agents can create similar fixtures in their test suites.**
