# Bug classes the audits miss, and what they over-report

Read at run time by all three proactive audits (code audit, security audit, doc
walkthrough). Apply the checklist for **your** lens; skip everything under
"Don't report". Each class names real fixes so you can see the shape.

The evidence table at the bottom is regenerated by
`python scripts/audit/miss_analysis.py --days 120`: run it monthly, and when a class
climbs or a new one appears, edit the checklists here. The prompts pick the change
up on their next run with no workflow edit.

## Missed classes — checklists

### No deadline
A wait with no timeout or progress check hangs the turn, the UI or a scheduled job.
#5346 (a hung MCP stdio server froze the turn), #5384 (page fetch, no overall
deadline), #5126 (model stream stopped sending), #5380 (scheduler job stuck firing),
#4933 (UI waited forever on a dead backend).
- **Code:** every subprocess, HTTP call, stream read, queue/lock/event wait, and
  polling loop in changed code has a deadline or a no-progress cutoff. Grep hits
  are listed in `audit-scope.txt` under "Calls with no deadline"; confirm each.
- **Code:** the timeout path tells the user what stalled, it does not retry forever.

### Shared state across processes
Two chats, the TUI and the UI, a daemon and a CLI, or GAIA and the user's own apps
all touch one model slot, port, file under `~/.gaia`, or process.
#5337 (one chat held the model from every other), #5282 (closing a TUI session
killed the shared model server), #5378 (concurrent token refreshes deleted the
connection), #5377 (a locked file index was deleted), #5345 / #5376 (GAIA killed the
user's own PowerPoint / ngrok), #4977 / #5318 (clients kept a port a restarted
server had left).
- **Code:** read-modify-write of a shared file without a lock or atomic replace.
- **Code:** teardown or cleanup that stops something GAIA did not start, or that
  another session still uses.
- **Code:** a port, URL or PID cached once and never re-read after a restart.

### Dishonest status
A command, tool result, health check or UI state reports success, "stopped" or
"not installed" when the truth is failed, busy or a missing extra.
#5112 / #5113 (failed commands and RAG outages reported as success), #4932 ("exited
early" instead of naming the missing `[api]` extra), #5317 (busy shown as stopped),
#5008 (an unfinished tool step shown as done).
- **Code (correctness owns this, with Fail Loudly):** exit codes, `ok`/`status`
  fields and UI labels match what happened; busy, down and failed stay distinct;
  the message names the cause and the fix.

### Cold start and non-default setups
Works on a warm dev box, fails for a new user or a non-default config.
#4951 (daemon first start timed out on a fresh install), #4919 (`--skip-models`
still downloaded), #4937 / #4952 (TLS-inspecting proxy, OS certificate store),
#4912 (remote `LEMONADE_BASE_URL`), #5130 (`GAIA_HOME` ignored), #4921 (`--pre`
pulled an incompatible httpx).
- **Code:** trace changed setup/startup code from an empty `~/.gaia`, no model, no
  daemon, a custom `GAIA_HOME`, `LEMONADE_BASE_URL` or port. Dependencies that
  can break on a major bump carry an upper bound.
- **Walkthrough:** you already start cold; flag any step that only works because
  an earlier guide's state is still around.

### Windows behaviour
#4927 (daemon started through a venv launcher not recognised), #5018 (background
processes flashed console windows), #4989 (`find`/`sort` with `/x` switches),
#5045 (start hint wrong in PowerShell), #5138 (stream readers not exiting).
- **Code:** subprocesses on Windows set `CREATE_NO_WINDOW` where a console would
  flash; paths are quoted; delete/rename tolerate a locked file; Windows PowerShell
  5.1 `>>` writes UTF-16 (never use it on a file another tool parses).
- **Walkthrough:** this runner is Windows. Report console windows, lock errors and
  shell-specific hints the doc gets wrong.

### Model output handling
#4973 (JSON answers cut at the first quote), #5103 (DSML tool-call markup answered
as text), #5121 / #5131 (envelopes and markup streamed into the chat), #5306 (model
reasoning stored as a memory).
- **Code:** parsers of model output handle quotes, partial streams and each
  provider's tool-call markup; raw markup never reaches the user or the store.

### Release and CI ordering
#4895 (final release notes based on the RC), #4954 (an RC version rejected), #5127
/ #5147 (main's unit tests red after a batch), #5133 (a test in no CI lane).
- **Code:** a new test file is collected by some CI lane; version comparisons
  handle `-rcN`; a workflow step does not read an output an earlier step only
  sometimes writes.

### Doc claim vs behaviour
#4944 (the agent rejected the `value` field its own spec documents), #5207 (the
installer's documentation link opened the home page), #4767 (a release sweep found
connector steps, CLI flags and a button the docs still described wrongly).
- **Docs:** for each doc a PR in `recent-changes.md` touched, or whose described
  behaviour a PR there changed, re-check its claims against the code now.
- **Docs:** hand-maintained tables (flags, tools, models, versions, profiles) match
  the code that defines them; a table is wrong as soon as one row is.

### Security (security audit only)
#5048 (shell allowlist checked only the first pipeline segment), #5218 / #5308
(a read or download path skipped the permission gate its sibling enforces), #5000
/ #4999 (cloud keys sent to a port another process could own), #5389 (installer
ran a download before verifying it).
- Every new tool path that reads, writes or executes goes through the same gate as
  its siblings; allowlists check every segment of a pipeline, chain or subshell.
- Credentials go only to the intended host and port, including after a restart.
- Anything downloaded and executed is checksum- or signature-verified first.

## Don't report

These made up most of the audit issues closed as noise. Report them and synthesis
will drop them.
- **"Module X has no tests"** on logic that guards nothing risky. File it 🟡 under
  `tests:aggregate-untested-modules`, never alone (umbrella #2988).
- **Code that no longer exists.** Confirm the path with `git ls-files` at HEAD.
- **Known umbrellas.** Add a comment to the open umbrella; never file a new issue:
  #1077 (a guide's prerequisites or `[extras]` are missing), #4331 (docs still say
  `lemonade-server serve`), #3308 (docs or templates name deleted agents),
  #3307 (a command reports success for something that did not happen), #2922
  (email package docs and code disagree on versions), #3195 (eval docs show output
  the tool never prints).
- **Already fixed.** Anything a PR in `recent-changes.md` fixed.
- **Walkthrough:** a step marked "requires X, not verifiable here" is coverage,
  not a finding.
